## 修复与预防

真实窗口测试曾抓到：锁定时设置新窗口形态被旧形态回写覆盖。修复为设置仍工作或待应用时禁止回写，相同用例通过。

审查同时修复：长图适应模式不应依赖锁定；改变拖动速度不应重置取景；连续缩放不应把每帧倍率累积到档位表；连续阅读需尊重当前页翻转；新页加载期间复制/打印不得借用上一页像素。阅读布局按图片边缘连续衔接，不人为给小图增加整视口空白。

测试脚本也修复了单文件目录下 `count` 键遮蔽哈希表 `Count` 属性的误判，不把测试脚本问题当成解码故障。

## 明确边界

- 多显示器真窗口用例 **跳过**：当前仅一块显示器。选屏保存/断开回退有单元与生产路由覆盖，不声称双屏实机通过。
- 新帧控件真实交互使用 GIF；APNG/WebP/实况的解码与时间轴由既有回归覆盖，未逐格式重复所有鼠标交互。声音设备与跨屏 DPI 的人工体验不能由状态探针代替。
- 本次不增加 PDF 解码、外部编辑器排序、RAW 高效率解码或安装程序。
