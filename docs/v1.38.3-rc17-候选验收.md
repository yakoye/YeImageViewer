# rc17 开发预览验收

本批只交付候选绿色包，不公开发布，不覆盖rc16。桌面仍按用户最近一次确认的“暂不可用”处理；不发送物理键鼠、不截图、不以离屏通过代替完整桌面验收。

## 修改与使用

- **倍率A保持**：同一图片在普通窗口/沉浸之间切换，只改变窗口形态，冻结实际显示倍率；窗口样式及尺寸消息的整个同步过程均受保护。人工缩放后以新倍率为准。首次打开和下一张仍应用用户选定的观看规则，不把临时手动缩放写成全局规则。
- **旋转条纹**：高质量缩小、缓存和连续阅读把未旋转的源宽高误传给要求“旋转后显示宽高”的映射函数。90/270度非方形图会越界，再被clamp铺成边缘条纹。三个入口改用统一源尺寸映射；不是针对某个文件名、分辨率或左上角颜色做特判。
- **颜色面板**：左侧当前页持续着色/粗体/左强调条；原色恢复本次基准色，当前色复制HEX，移除重复恢复按钮；近期色悬浮显示HEX及本地采集/记录时间，无有效时间则显示未知。
- **保存**：旋转或镜像后在主窗口出现非阻塞操作条“保存到原图 / 保存到副本 / 否”。未明确点保存不写图。“否”只关闭提示，不撤销浏览结果。设置可以关闭提示。保存原图仅接受完整8位单图PNG/JPEG；JPEG另外确认重编码风险，高位深、动图、复杂格式、MPO和尾附视频等保留副本路径。PNG/JPEG保留摄影元数据、更新方向/尺寸/sRGB并清除过期缩略图，验证新文件后同目录替换，原始字节另存唯一 `.before-edit-{GUID}.bak`。替换失败保留备份/新图恢复文件，提交前发现源文件变化则拒绝。不是面向恶意并发进程的文件系统CAS保证，也不声称所有厂商私有元数据都能无损编辑。失败状态处理参考 [微软ReplaceFileW说明](https://learn.microsoft.com/windows/win32/api/winbase/nf-winbase-replacefilew)。
- **右键拖动缩放**：设置中默认关闭，可选上放大/反向，灵敏度20档。越过4DIP阈值才进入拖动，缩放锚定按下位置；拖动完成或捕获取消吞掉右键松手，避免误退出。Ctrl+右键保留固定菜单。左键拖动、滚轮、智能加速与惯性设置不变。
- **图层每行速度**：移植固定Photocraft上游的原层/蒙版有界采样，最多128×128，界面请求32×32，不再为了每行缩略图调用整画布合成。原层缩略不包含整图重合成的全部混合效果，与上游列表口径相同；主画布仍使用原合成路径。
