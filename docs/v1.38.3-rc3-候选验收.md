# v1.38.3-rc3 候选验收

开发日期：2026-10-18；续验日期：2026-10-19。延续 rc1/rc2，独立候选归档，不公开发布。

## 本轮调查与缺陷

用户暂停其他桌面自动化后，`artifacts/image-tools-rc2-uninterrupted.log` 中1242项单元/集成、17项源码只读隔离检查、143个PNG逐字节比对、真实Shift+F10、80项观看、此前受前台干扰的TB-04微拖、WASD和独立滚轮均通过。但滑杆第6档重新打开弹层失败，整轮退出1，不能称完整通过。

随后分项补验记录在 `artifacts/image-tools-rc2-tail-*.log`：滑杆56项、惯性148项、工具栏视觉、DPI、实际大小、常规设置113种组合/339项断言、快捷键/滚轮94项断言以及归档契约均通过。轻工具最后恢复边框探针却出现一次形态没有变化：倍率仍为0.225494，最终`shape=1`。重试通过不能解释失败，不把它当作已消失。

根因是点击路径依赖此前 `OnMouseMove` 留下的 `cursorPos` 和工具栏可见状态，没有先按本次按下坐标刷新命中。悬停状态与按下位置不同步时，手掌区域可能被忽略，留白也可能不进入恢复边框分支。这是点击路由问题，不是此前已修复的恢复边框重算倍率问题。

修复在空闲左键按下时复用既有坐标命中流程；已有图片拖拽、窗口拖动、滑杆捕获、动图帧拖动期间不补发移动，避免把点击修复变成额外拖拽增量。旋转、镜像、缩放与惯性规则不改变。
