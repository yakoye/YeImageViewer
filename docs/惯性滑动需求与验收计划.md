# 惯性滑动需求与验收计划

日期：2026-10-13。用户确认：默认关闭，需要独立灵敏度；现有智能加速及固定倍率的按住拖动不变。

## 范围与规则

- P0：新增「拖拽惯性滑动」关闭／开启，及独立「惯性滑动灵敏度」1～9 档，默认 5。档位越高，松手后衰减越慢、滑行越远；不影响按住拖动速度。
- P0：只在图片左键快速拖动后松手触发，按最近约 120 ms 的鼠标速度判断快速手势、按已经实际移动的图片速度衔接。固定倍率／智能加速二选一，不再次叠乘倍率。
- P0：松手后的速度连续减小，到时完全停止。原有单轴／双轴／边界规则统一适用，不回弹、不露越界空白。
- P0：慢拖、最后停顿超过 80 ms、Shift 精细手势、工具栏／滑块／信息面板／窗口拖动不触发。任何使用过 Shift 精细模式的本次手势均不甩动。
- P0：再次按鼠标、滚轮、键盘、菜单、切图、旋转、缩放、窗口尺寸改变、失焦、捕获异常立即取消惯性。连续阅读的自然跨页不当成人工切图取消。
- P0：静图、动图及纵／横向连续阅读共用减速策略。设置保存到新的保留区，不改变 4096 字节结构，也不删除外部编辑器／文件目标／旋转记录。
- 非目标：不增加滚轮惯性、不更改已有滚轮映射、不增加边缘回弹，不自动公开 GitHub。

## 实现与验证

1. 单独封装最近速度采样、快速释放判定、有限时长减速曲线，单元核对九档单调性、时间步长独立、速度上限及损坏配置。
2. 接入生产鼠标按下／增量／松开生命周期；采样使用实际限位后的图像位移，触边不能残留虚假速度。
3. 设置页增加两行，绘制／命中／滚动高度／三语字符串／选项计数同步调整。
4. 真窗口在隔离 EXE／DB／生成长图中验证：默认关闭；开启后松手继续；九档；慢拖／停顿／Shift 不甩动；边界；输入／失焦打断；自动与固定不叠加；连续阅读；退出重启设置保留。
5. 运行完整 `runTests.ps1`；候选版递增为 `v1.38.1-rc2`，不覆盖 rc1，验证绿色包并复制两处候选归档。Win10／4K／混合 DPI 双屏仍需真机验收，不冒报通过。

验收成功：默认关闭时原有拖拽回归全部保持通过；开启后原生窗口实际出现持续减速的位移，且用户可随时停止。长期耐久测试与人体手感不由保存值断言替代。
