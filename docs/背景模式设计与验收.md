# 背景模式设计与验收

## 用户确认的行为

普通窗口、沉浸显示和全屏统一使用所选背景，不再给沉浸留白额外套黑色压暗层。

| 右键菜单 → 背景颜色 | 实际效果 |
| --- | --- |
| 透明 | 窗口客户区留白和图片完全透明像素均透出背后内容；半透明图像保留预乘透明度，不降低整张图片或工具栏的不透明度 |
| 白色 | 精确、不透明白色 |
| 黑色 | 精确、不透明黑色 |
| 毛玻璃 | 系统合成器对背后的实时窗口内容执行模糊，图片自身保持清晰 |
| 棋盘格 → 跟随配色方案 | 按软件当前浅色/深色配色自动选择格子；配色为跟随系统时随系统变化 |
| 棋盘格 → 浅色／深色 | 固定指定格子颜色，不随主题变化 |

棋盘格子宽12像素；浅色为245/235灰阶，深色为60/48灰阶。格子以客户区坐标定位，不随图片拖拽移动。

透明只针对画布和图片透明像素，不透明图片不会变半透明；窗口标题栏、工具栏、停靠面板不被整体透明化。此批不改变窗口切换、缩放和拖拽行为。

## 兼容与降级

- 背景原有编号0～3不变，新增棋盘格为4。`SettingParameter`字段顺序/大小不变。
- 棋盘格配色独立占用reserve[368..371]，具有自己的magic/version，旧设置默认自动。不修改其他配置区或文本尾部。
- DirectComposition支持预乘alpha时透明画布为0，半透明源像素先预乘再上传，不把棋盘格混入图像。
- 毛玻璃优先请求系统背景材质；不以新版alpha属性成功与否判定既有合成表面可用。
- Windows 10兼容路径动态探测`SetWindowCompositionAttribute`的blur-behind能力。此导出非公开稳定契约，不静态链接；切换其他背景先禁用旧模糊。
- 模糊请求全部失败时使用实色并通过现有顶部提示明确说明。合成alpha不可用时也明确提示，不声称当前具备透明效果。
- 系统高对比度、省电、远程图形环境可能影响材质外观；当前机器真窗口通过不能代替每个Windows版本的实体机验收。

微软资料：[系统背景材质最低支持Windows 11 build 22621](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)；[旧DwmEnableBlurBehindWindow从Windows 8起不再产生模糊效果](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmenableblurbehindwindow)。因此不能只调用旧DWM函数就声称Win10毛玻璃已完成。
