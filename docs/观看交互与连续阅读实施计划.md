# 观看交互与连续阅读实施计划

日期：2026-10-12。状态：功能实施及首轮验收完成，提交后发布闸门待执行。

## 用户问题与目标

切图后观看规则被覆盖、预览和原图反复改变窗口，要求用户逐张重新调整。普通窗口的信息面板缺少直方图，缩放和逐帧交互不完整；连续阅读还需要单/双页、双向排列和简单配对纠正。

目标：选项跨切图/重启稳定；读到首尾行为明确；每个可见按钮及快捷键有一致命令；连续阅读不丢页、不重复、纠正配对不跳回开头；回归与实机验收全部完成后公开发布。

## 范围与用户故事

- 普通看图：记住沉浸/普通/全屏形态与默认缩放规则；临时缩放仅作用于当前图片。
- 检查图片：任意窗口模式都能查看分辨率与可选直方图，复制基础信息和 EXIF，面板无底部按钮栏。
- 查看动画：显示当前/总帧，拖动定位、自动暂停逐帧、从暂停处继续。
- 连续阅读：纵向/横向、单页/双页，点击确定当前页，一键指定左/右位置并保存当前文件集配对。

本次不新增 PDF 渲染器，不改外部编辑器排序，不接入 RAW 高效率解码，不做安装程序。PDF 仅是双页配对交互的参考；RAW 诊断问题另开实现范围。

## 分阶段计划与验收

### 阶段 1：独立观看策略与持久化（发布必需）

- [x] 新增独立配置：窗口形态、默认缩放、普通窗口尺寸策略、锁定、允许放大小图、循环浏览；增量迁移旧设置，保持 4096 字节布局及文本区。
- [x] 锁定以规则为准而非上张百分比，切图重新计算，跨启动保存；手动放大/平移不更改默认规则，明确模式/缩放命令保存新选择。
- [x] 启动沉浸与尺寸策略解耦；沉浸/全屏下窗口适应图片不可用，不强制退出。
- [x] 同一次打开过程中按真实尺寸确定几何；预览替换不重设用户缩放，不重复调窗口。
- [x] 长图可选原始 100% 从顶部开始，或适应窗口；原始模式不按窗口宽度缩小/放大。长图识别以旋转后的宽高比和纵向溢出为准。
- [x] 长图可保持水平居中、只上下拖动，缩放后仍居中；图片拖拽提供 1×/2×/3×，窗口拖动、面板滚动不加速。
- [x] 循环开关统一约束键盘、鼠标、菜单、工具栏、幻灯片；关闭时首尾停止，短提示限频。
- 验收：横/竖/小/长图、缓存命中/渐进加载、旋转、关闭重开、旧设置迁移、模式组合；新增缺陷用例先在旧行为下失败。

### 阶段 2：信息面板与提示（发布必需）

- [x] 普通/沉浸/全屏均尊重直方图开关，基础信息始终包含分辨率；高度自适应并允许滚动。
- [x] 删除整条底栏、占位和命中区域，保留右上关闭、信息切换/复制快捷键及自定义冲突规则。
- [x] 复制信息走统一顶部 Toast，不更改 C 的用户绑定；滚动面板不同时缩放图片；Esc 维持用户自定义。
- 验收：三语、浅深主题、多 DPI、小窗口、面板复制/滚动/关闭、C 改绑。

### 阶段 3：缩放质量、连续缩放与动画控制（发布必需）

- [x] 显示质量三档：高质量抗锯齿、快速、像素清晰；100% 不模糊，缩小过滤与透明边缘正确；重用缓存，避免高频同步 I/O。
- [x] 短按缩放分档，长按按时间连续倍率变化，松开停止，失焦/菜单/弹窗取消按键保持态；不依赖系统重复速度。
- [x] 原有动图栏增强：当前/总帧、帧进度条、拖动暂停，逐帧自动暂停，原时长继续播放；常显选项，静图不显示，实况声音规则不变。
- 验收：斜线/文字/棋盘格/透明边缘，缩放正反对称与重复消息，GIF/APNG/WebP/实况、变帧时长、拖动首末帧。

### 阶段 4：连续阅读（发布必需）

- [x] 四种组合：纵向单页/双页、横向单页/双页；双页均左右并排，各组沿阅读轴连续衔接。
- [x] 每页/组依默认规则布局，保持比例；可见页按需解码，附近页预取，离屏页受 LRU 限制，不一次加载整个文件集。
- [x] 点击页确定当前图片，信息/复制/删除命令针对当前页；单页翻页到下一页，双页翻到下一组，临时缩放不改默认规则。
- [x] 当前页置左/右整体调整配对；首尾补空白，不丢页、不重复、不改文件顺序；重排/方向切换保持当前页附近阅读位置。
- [x] 全局保存阅读布局/方向，文件集保存配对；存入已有配置文本区并保留其他模块键。
- [x] 阅读控制条与右键菜单入口明确，不增加仅为右键菜单服务的浮动工具栏按钮；首尾连续阅读不拼接循环。
- 验收：1/2/奇数/偶数张、混合尺寸、负向/横向滚动、配对纠正、重启/换文件集、删除当前页、坏图/慢图、持续翻页与内存控制。
