# YeImageViewer 取色器与颜色助手 — 测试计划与用例

- 测试设计版本：1.0
- **状态声明**：本文件全部是**计划测试**，尚未运行；`NOT_RUN` 不可擅自标成 `PASS`。
- 目标：Codex 开发一项 → 执行对应测试 → 在真实报告记录环境/步骤/结果/缺陷。

## 1. 测试环境矩阵

| 组合 | 要求 |
|---|---|
| OS | Windows 10/11（以 YeImageViewer 实际受支持版本为准） |
| 显示器数量 | 1、2、3；支持更大配置的用户环境可补 |
| 显示器位置 | 左右、上下、呈 L 型、含虚拟桌面空洞 |
| 分辨率 | 1920×1080、2560×1440、3840×2160（可选） |
| DPI/缩放 | 100%、125%、150%、200%，混合显示器不同 DPI |
| 显示模式 | SDR、HDR 开/关（如设备支持）；镜像/扩展和主副屏交换 |
| 会话 | 本地桌面、RDP、显示器热插拔后 |
| 图片 | 8-bit RGB、RGBA 透明、灰度、旋转、镜像、动图、大图、带 ICC 配置（在实际支持的格式内） |
| 系统主题 | 浅色、深色、跟随系统 |

所有像素正确性测试应使用**已知颜色参考图**，例如 1px 棋盘、边缘纯色条、固定 `(x,y)` 色块和含半透明点的 PNG；实际参照坐标必须记录，不能靠目测。

## 3. 自动化测试项目

必须具备（以项目既有测试框架实现）：

1. `ColorMathTests`：HEX parser, RGB/HSV/HSL, LAB D65, CMYK black, HSI grayscale, clamp, inverse/error tolerance。
2. `CoordinateMapperTests`：负屏幕坐标、虚拟桌面矩形、多 DPI 分辨、边缘变换与 HUD clamp。
3. `ImageCoordinateTests`：缩放/旋转/镜像/平移/边界/透明像素。
4. `PaletteEngineTests`：hue 归一化、互补/类似/三角色、渐变色标、对比度。
5. `StorageTests`：读/写/版本升级/损坏文件/备份恢复/导入导出。
6. `PickerStateMachineTests`：Idle→Picking→Selected/Cancelled/Error，重复启动/失败清理。
7. `ImagePaletteTests`：含已知像素直方图的输入图预期主色，异常透明图片、取消任务。

手动测试必须附“截图/视频/记录 + 设备和缩放比例”；尤其多屏、HDR、RDP、真实剪贴板无法仅靠算法单测代替。
