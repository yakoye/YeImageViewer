# UI 与交互规格（按用户7张截图）

## 一、入口和主流程

1. Viewer工具栏添加吸管按钮，菜单入口：屏幕取色、图片取色、颜色助手、历史。快捷键依既有源码冲突表定最终默认值；全局热键默认关闭。
2. 快速取色默认“HUD -> 左键确认 -> 自动复制 -> 短提示 -> 返回原工作”，**不要强制打开颜色助手**；完成提示可进“调整 / 历史 / 再取一次”。
3. 右键或Esc取消：不复制、不入历史、不更改当前选色；复制失败须告警、不隐瞒。
4. 任何时候可单独打开颜色助手，工作台一个实例并记住上次页面；所有页面共享一个当前颜色状态。关闭助手不关闭Viewer。

## 二、全屏HUD（图1）

- 15×15/17×17等奇数格；中心突出描边与十字，精确物理1px采样；放大倍数可以调整而不改变取样；网格与准星可开关。
- 默认显示：坐标 `(x, y)`、带坐标模式标签、实色块、HEX/RGB/HSL/HSV格式标签和数值、紧凑快捷键说明。
- `Shift`循环HEX→RGB→HSL→HSV（在取色态有效）；`P`切屏幕绝对/当前显示器相对；`C`复制保留HUD；`Enter`或左键确认；`Esc`或右键取消；方向键移动1物理像素；`Space`冻结/继续实时取样。快捷键最终应在源码审计后与现有键位冲突消解，并写帮助。
- HUD避让：不允许遮挡准星，按每个显示器的物理边界自动翻转，避免在阈值附近晃动。支持不足容纳窗口时的紧凑布局，超出屏幕的采样格显示“无效”。
- HUD样本来自桌面最终呈现的像素，保护区域不能抓取时明确提示；遮罩自身不得混入采样。若取色到窗口外或从截图冻结，需要清楚显示状态。

## 三、取色后颜色调整（图2/3）

- 左：可交互色相/饱和度/明度选色盘，当前色大背景，原色/当前色双重对比，带标签的滑块。
- 右上：互补色、类似色、对比色、中差色（均有实际计算公式，按钮/色卡显示名称/HEX，点击应用或右键复制/收藏）。
- 右下：每行颜色格式独立编辑或明确只读、右侧复制按钮：HEX/RGB/HSV/HSB/HSL/CMYK/HSI/CIELAB/RGBA(图片模式)。
- 底部：原色恢复、撤销、重做、收藏、取消、应用。有效编辑提交新历史记录。拖动仅保留一个撤销事务。
- 在窄窗口下右侧面板换到底部Tab，避免截图样式固定宽度引起裁切。

## 四、颜色助手页面最终完整范围（图2～7）

| 页面 | 必备UI与交互 | 参考图 |
|---|---|---|
| 颜色 | 色轮+明度滑块+颜色字段+推荐色+前后对比 | 2/3 |
| 取色历史（新增优先） | 颜色样本、时间、来源、坐标可选、筛选/搜索/复制/再编辑/删除 | 新增 |
| UI色卡 | Flat UI、Fluent、Open Color、Ant、Material；色阶/类别/筛选/复制 | 4 |
| 图片色卡 | 当前图片/导入/剪贴板/拖入/选区提色；占比/排序/导出 | 2的侧栏项 |
| 传统色 | 中国24节气/日本传统色，分组彩色网格，名称/HEX/搜索 | 5 |
| 渐变色 | 网格卡片、顶部色系筛选、编辑色标、角度、线性/径向 | 6 |
| 收藏颜色 | 空状态和`+`，单色/渐变/调色板分组、标签/排序/编辑 | 7 |
| 离线智能配色 | 规则配色模板、UI角色(背景/主色/文本/强调)、示例预览 | 新增 |
| AI配色（P4） | 用户描述/提供商可选/发送授权/方案预览/编辑/收藏 | 2的侧栏项 |

建议导航按常用程度排序：`颜色 → 历史 → UI色卡 → 图片色卡 → 传统色 → 渐变色 → 收藏 → 智能配色 → AI配色`；初始只有已实现的页面可操作，后续阶段必须补齐。

## 五、统一操作/右键菜单

- 选中颜色：单击应用/选中；双击复制可以配置；右键提供`复制HEX / RGB / HSL / HSV / 在编辑器打开 / 收藏 / 删除(仅用户数据项)`。
- hover不修改主色历史；仅明确提交才入历史。颜色使用非仅靠色相区分的选择边框，方便色觉缺陷用户。
- 一套剪贴板格式化器服务HUD/编辑器/历史/色库/收藏；复制提示不可误触。
- 三态主题浅色/深色/系统；提供字体高DPI、键盘导航、输入提示、确认与撤销，文本不遮挡。
- 默认离线；支持自定义数据导入导出，导出数据时显示保存路径且路径无硬编码账户名。
