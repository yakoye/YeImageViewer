## 追踪规则

1. 不因优先级调整删需求、删测试、删功能菜单；页面实施之前可以标“规划中”，但最终应完成。
2. 每次提交必须将 `REQ-ID -> 源文件/PR -> 单测/集成测试ID -> 实测结果 -> 缺陷/CHANGELOG` 串联。
3. 完成率分为“开发实现”“测试执行”“实际通过”三个数字，不能用源代码中存在一个空页面来宣称功能完成。
4. 发布Gate以单个阶段的真实结果决策；全量最终验收必须覆盖100个原始+本版新增用例；v1.1另81条需核对是否存在本版遗漏的行为，不能作为缩减依据。
5. 测试未执行统一标 `NOT_RUN`。条件缺失标 `BLOCKED`，记录阻塞原因；AI被用户明确取消后才可通过更新需求范围标记不适用。
