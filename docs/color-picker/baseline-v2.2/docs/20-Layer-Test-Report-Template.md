## 实验前检查
- 原始文件只读保护、保存前后 SHA256 相同；一份原图 + 一份包含组/智能对象/蒙版等层的文件。
- Windows 开启调试日志, 性能采样清楚区分：PSD 解析、Merged 解码、缩略图生成、重合成、GPU 呈现。
- 截图取证必须在同一文件、同一层可见性、相同颜色模式及视图 zoom 条件下比较。
- 通道预览需要注明灰度/彩色模式、像素深度、是否显示 ICC 变换后的结果。
