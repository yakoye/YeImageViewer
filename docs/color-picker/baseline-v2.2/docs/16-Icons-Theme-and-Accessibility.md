# 16 · 统一图标、主题、交互规范

## 主原则
先检查工程现有 `OverlayLayout.h`、`ToolbarCommand.h`、资源表和已有图标资源及图标绘制方案；**尽量只在原有体系内增加一个标准吸管 icon**，不引入第二套 UI 框架和附加图标包。不允许 emoji 作为最终 toolbar 图标、Unicode 字符替代按钮图标或不同风格混用。

## 建议图标（需用已有图标规范实现）
| 功能 | 图标语义 | 建议标准名称 (Lucide/Tabler 同类) |
|---|---|---|
| 取色 | 吸管 | `pipette` / `color-picker` |
| PSD 图层 | 重叠图层 | `layers` / `stack-2` |
| 通道 | 三个重叠圆 / 分离色通道 | 先复用现有工程等线条风格资源，再定具体资产 |
| 展开/折叠 | 小三角方向 | `chevron-right/down` |
| 图层可见/隐藏 | 开眼 / 斜线眼 | `eye` / `eye-off` |
| 还原 | 重置箭头 | `rotate-ccw` |
| 保存副本 | 保存/下载 | `save` / `download` |

## 交互规格
统一 20px 基准图形/34px 按钮命中区（结合既有 BASE_ICON_SIZE / BASE_BUTTON_SIZE），同一线宽、视图盒、对齐基线、hover/pressed/disabled/focus；鼠标、键盘、触摸笔命中与绘制区域一致。
- Windows DPI 100/125/150/175/200%, 右侧/上方/负坐标屏；窗口很窄时不能点击到相邻按钮。
- 浅色、深色、跟随系统；背景与图标至少达到常规可辨识对比度；色盲用户不能只靠红绿判断层状态。
- 全中文/英文/繁体文案沿用现有 UiLanguage 规范；tooltip 提示功能 + 当前快捷键 + 状态，不能硬编码已失效的热键。
- 只读/待加载/功能不支持三种状态必须有区别，面板可键盘操作，有无图层不产生灰色常驻死按钮。
- 图层面板宽度建议可调 260-360 DIP 并持久化，自动依据工作区边界限宽，宽窄窗口无覆盖主要控制。
