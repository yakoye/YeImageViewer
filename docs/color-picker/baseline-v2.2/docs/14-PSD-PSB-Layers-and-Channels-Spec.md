# 14 · PSD/PSB 图层与通道可浏览功能（重点）

## 产品边界
YeImageViewer 是**查看器**，优先做好“忠实显示已有文档 + 临时试验图层显示”。不以新建/删除/像素绘制/编辑文字/原位保存 PSD 为目标，不伪称 Photoshop 兼容编辑器。任意图层显隐操作、通道选择、合成渲染都是**会话内非破坏性状态**，默认原文件不变。

## 为什么参考图1不达标
当前原型右侧占据约1/5屏，亮色面板和沉浸式视图不和谐；文字列表层级、缩略图、组选中样式不足。更严重的是它出现“本次操作未应用，保留上一画面”状态，证明 UI 可切换不等于已经重建了 Photoshop 画面。要先修“功能能力与提示一致”，再调 UI 美化。

## 首屏合成忠实性（最高优先级）
1. 优先读取 PSD/PSB 中的**真实合成图**（Composite/Merged Image），保留原 ICC/颜色模式的已有转换规则。合成图作为默认预览，也是原始对照基准。
2. 图层控制时进入“会话重建合成预览”，仅当所涉层/分组的类型、蒙版、混合模式与颜色空间被当前渲染器支持时启用可生效的眼睛开关。
3. 对不能准确合成的智能对象、文字特效、形状、调整图层等不应静默变成普通像素；若只读元数据，明确标“只读/无法预览切换”；提供“返回原始合成”一键恢复。
4. 重建失败不得变成黑屏、透明或永久留旧画面，却又让眼睛图标看起来成功；要原子提交帧：成功后整体替换图像，失败回退到已知良好帧并提示未生效。
5. 不要求两张用户截图每像素一致：图2 Photoshop 选中组3，其截图可能是当前编辑过程中的不同可见性状态，必须使用同一个文件、同一层可见集合、相同色彩管理与放大倍率进行 A/B 比较。

## 图层面板 UI：以 Photoshop 为交互参考，保持查看器轻量
- Tab: **图层 / 通道**，始终同一浮动/停靠容器；优先深色主题，浅色及系统跟随一致。
- 顶部：`原始合成` [恢复] [可见的层数/总层数]；可选 `[展开所有] [折叠所有] [只显示选中]`。
- 图层列表：**眼睛状态 + 缩进树线/展开三角 + 缩略图 + 图层名称 + 类型小标 + 状态**；支持滚动、长名称省略号与 Tooltip、中文/Emoji/非 BMP 字符。
- 组：展开/折叠、组级显隐级联（不改子元素各自原来的可见标记）、部分可见中间状态；选中组只查看范围/元数据，无“修改文档”含义。
- 缩略图：优先真实图层、蒙版/智能对象有区别标识；异步解码+虚拟化，不能因为超过数百图层卡 UI；透明缩略图绘制棋盘格。
- 选择和查看：单选高亮、点击缩略图不切换显隐；单击眼睛只切可见性；选中层后显示名称、尺寸/偏移、可见/锁定、混合模式、透明度（**只读字段**，除非确有可预览调节能力并做可撤销会话）。
- 有些组的独立“Pass Through”混合模式、剪贴蒙版、调整层会影响整个图像，不得当成简单 alpha 合成处理。
- 面板底部：`返回原始合成`；明确标识 `原始合成` / `图层重建预览` / `部分支持`。如果需要占位/预计算，应可取消且不阻塞切换图片。
- **通道**：RGB 合成及 R/G/B、Alpha（仅存在时）、文档原生 CMYK/Lab/Gray 及专色信息；支持 `灰度查看单通道`、可选彩色显示；通道缩略图/名称/显示状态；不要把 Alpha 当作普通颜色层，也不要把“复合RGB”解释成全文件真实色彩空间。
- 通道选择是“查看”且不能改变源文件，切回 RGB 或原始合成恢复可预测；取色器在单通道界面需显示“当前查看颜色”和“原始合成色”的来源标识。

## 图层树/合成技术准则
- PSD v1/PSB v2、图层顺序（源文件与 UI 视觉顺序映射清楚）、组分隔记录、Unicode 层名、长图层名、虚拟层、空层、层边界外溢、裁切与超画布。
- 每层：LayerId、类型、rect、visible、effectiveVisible、opacity、fillOpacity、blendMode、groupMode、clipping、mask bounds/data、channels & depth、unsupportedReason。
- 合成：文档不同位深(8/16/32bpc)、RGBA、CMYK/Lab/Gray 色彩及 ICC 处理；逐层 alpha 正确采用预乘/非预乘一致策略；Group knockout/PassThrough/Blend-if/LayerStyles 需要能力判定，不做即禁用/标注。
- 渲染组织：工作线程延迟解码目标层，缩略图异步与缓存；图层显隐触发增量或整图重建、generationId 防止老任务覆盖新结果。中止时回收资源；控内存并降级。
- **不支持原位 PSD 编辑保存**。需要保留当前重建结果时：“导出当前预览为 PNG/TIFF/WebP 等副本”，原 PSD 永不覆盖；如果未来实现真 PSD round-trip，单独立项。

## 难度阶段（不能掩盖能力）
- L0：准确识别图层存在、稳定树列表 + 缩略图 + 只读信息、显示保存的原始合成 + 通道浏览。
- L1：支持图层基本像素层/普通 alpha/已实现 blend 的开关并**真实**更新画面；组级显隐、恢复原合成、预览导出。
- L2：特殊合成语义、调整层、遮罩、CMYK/Lab/高位深/ICC、复杂文档扩大覆盖。各类按真实测试逐项开放可切换状态。
- L3：更完整兼容，绝不未经验证宣称 Photoshop 像素一致。
