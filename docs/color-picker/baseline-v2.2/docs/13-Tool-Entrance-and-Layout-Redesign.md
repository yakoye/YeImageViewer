# 13 · YeImageViewer 工具入口与界面重整（新增决策，2026-10-20）

## 性质与优先级
本文件补充 v2.0，不删除原先 259 条测试和任何颜色助手功能。依据用户最新截图：参考图1是当前叶图图层原型，参考图2是 Photoshop 目标，图3是旧“轻工具”入口，图4是当前下方工具栏。

## 确认方案
- **取消“轻工具”这一中间菜单**。不是取消取色、旋转、镜像、图层能力：它们应迁到明确的一级位置，右键菜单仅保留直达功能（如已有入口，不再以“轻工具”套一层）。
- 底部工具栏保留现有设置、左/右旋转、水平/垂直翻转、拖动倍率、图片导航、缩放、全屏等；在 **“上下镜像/垂直翻转”右侧、拖动倍率之前** 插入一个吸管图标作为颜色取色器入口。
- 原始 OverlayLayout 使用 `BASE_TOOLBAR_WIDTH=615+PAN_INSERT_WIDTH`，左侧 `flipVerticalRect` 偏移155，`panMultiplierRect` 偏移193；必须整体调整其后布局常数及命中测试，**不能只把图标画进去，却不改变按钮点击区域**。
- 吸管支持“图片原像素取色”和“屏幕全局取色”的已设计模式。工具栏主点击优先启动原图片素取色；附属入口（图标右键、长按或可配置设置之一）选择全屏取色，避免意外屏幕捕获。独立快捷键均需在设置中可查看/修改并检查冲突。
- **图层入口条件化**：仅文件具备已成功解析的图层信息、且有实际可浏览分层内容时启用“图层/通道”徽标；PSD、PSB、PSDT 等格式仅为候选，不代表一定有层。单层 PSD 可以呈现有图层的信息，但默认不弹面板；完全扁平 PSD 不弹图层提示。通道若有可浏览能力，可以由相同入口打开，不必显示两个永久按钮。
- 默认不遮挡画面：首次检测到有多图层文档时，顶部/侧边出现一次可关闭的非阻断提示“检测到 N 个图层 · 查看图层”；之后同文件不再频繁弹。角落小图层图标在文件浏览期间可出现（悬停工具栏或首次提示后短暂露出）；可固定侧栏，记忆“自动/始终折叠/始终展开”的设置。
- 图层面板 **右侧浮动或停靠**；浅色/深色/跟随系统三态主题；窄屏时使用覆盖式抽屉，不把图片挤到零宽；退出面板图层状态仍在同一会话内可恢复。

## 工具栏示意（逻辑顺序，不锁定像素宽度）
`[设置] | [旋转左][旋转右][水平镜像][垂直镜像][吸管] | [拖动倍率] | [上一张][播放][下一张] | [适合/原大/全屏] | [-][倍率][+]`

**设计底线**：不增设第二排、不开“工具工具菜单”、不加未使用的固定 PSD 按钮；按钮间距/分组/hover/hitbox/tooltip/键盘可达性统一设计。若窗口太窄，必须定义智能收起次要按钮策略，关键入口可通过快捷键和菜单访问。隐藏≠删除。

## 页面/文件状态
`FlatImage`, `LayeredDocument`, `ReadOnlyMerged`, `LayerDecodePartial`, `LayerDecodeReady`, `RecomposeReady`, `RecomposeFailed` 等能力状态必须与 UI 告知一致。不得以扩展名假定可切图层，也不得以画面保持上一帧伪装开关成功。

## 交互验收
- 普通 JPG/PNG/RAW 无常驻 PSD 面板；打开 100 个普通文件不闪现 PSD 图标。
- PSD/PSB 仅在有效图层/通道内容时有入口，首次轻提示；点击无阻塞进入。
- 图层窗口点击关闭只隐藏，不导致图层数据损坏；切普通图自动隐藏且下次加载正确。
- 底部吸管严格位于竖向翻转右方；拖拽/缩放/响应/布局/快捷键无回归。
- 历史版本色轮/色卡/传统色/渐变/收藏/历史和 AI 最后阶段全部保留。
