## C. PSD 会话状态机（增量实现）

1. `SourceComposite`：读原 PSD 保存的合成图，默认显示。此状态不得被手写重合成污染。
2. `LayerDataPending`：用户打开面板时解析元数据/图层树，工作线程惰性解码；提供可取消和超限降级。
3. `LayerPreviewReady`：图层预览可重算；眼睛开关先在临时状态计算，成功后原子提交新的可见结果和眼睛标识；失败完全回滚。
4. `UnsupportedPartial`：有不可忠实重合成的调整层、组穿透、矢量/文字/智能对象或不支持的混合模式时标注原因；不允许用最后帧覆盖 UI 假装更新。提供“原始合成”和“尝试部分预览”两个清楚选项。
5. `SourceRestore`：恢复真实原始合成、原始显隐快照和面板状态；不触碰文件。

处理前后预览必须与 Photoshop 基准/独立参考或可重现的纯像素小夹具对照，支持透明与棋盘格、RGB/CMYK/Lab/16bit/PSB 场景。性能基线记录首帧、打开面板耗时、显隐合成时延、峰值内存和 UI 响应。

## D. 新的统一入口

- 吸管：底部 `FlipVertical` 右侧，调用画面取色模式并可切换“当前图片真实像素”和“屏幕任何区域”；复制/历史/进入颜色助手。
- 图层与通道：**只对探测到可展开多层/通道数据的文档**显示小按钮或首次短暂引导；普通 JPEG/PNG、无可用图层 PSD 不显示（或仅显示可访问的色彩通道信息入口，前提是不混淆）。菜单项可继续放“查看”组，绝不再藏于“轻工具”。
- 旋转与镜像：原有 4 个按钮保持；操作后显示非模态小胶囊 `已调整预览（记住方向）  保存副本  撤销`，用户可以点击；淡出时不隐含写入原图。提示有键盘可访问替代入口，但不得抢已有快捷键。反复操作合并最后一次变换，导出前显示格式、路径、编码和风险。
- 图标：使用仓库同系列 SVG 的尺寸、视口、线宽、禁用态、hover/focus、浅/深/系统三态；重新绘制布局时添加自动截图/像素回归。

## E. 推荐开发阶段（不删范围）

1. **C0 候选盘点及基线冻结**：记录真实本地候选、SHA、dirty 文件、现有测试日志；避免重写现成模块。
2. **C1 高优先级取色**：屏幕全域、取色后调整、历史，以及吸管与轻工具菜单合并、图标/键位重整。
3. **C2 图层/通道 UI 稳定**：真正条件出现、正确树结构、通道视图、状态与失败提示。
4. **C3 图层重合成正确性**：从基本层到组/透明/蒙版/混合模式；复杂层不支持要明确标注；性能/内存门禁。
5. **C4 旋转镜像可保存**：toast 操作 + 导出/冲突/撤销/旋转记忆分离及回归。
6. **C5 完成所有 v2.0/2.1 色彩功能**：UI/图片/传统色/渐变/收藏、导入导出、离线推荐；AI 最后。
7. **C6 全量回归和发布候选**：代码/测试/文档/版本链闭环；达到真实发布门禁后，仍须用户明确决定是否公开发布。
