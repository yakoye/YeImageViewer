# 需求决策与冲突解决记录（v2.0）

| 冲突/变化 | 本版统一决定 | 理由 |
|---|---|---|
| v1.0有100条，v1.1只有81条 | 保留v1.0原100条，并扩展新增测试；v1.1完整存档 | 不能因优先级调整减少验收范围 |
| v1.1强调前三件事 vs v1.0完整助手 | P0/P1a/P1b先做，P2/P3/P4继续；全功能最终交付 | 先做不等于删功能 |
| AI配色是否删 | 最后P4实现，默认禁用联网；用户未来明确决定后才取消 | 最新要求“所有提到功能都需要开发” |
| 快捷键C复制是否入历史 | 默认仅确认/应用入历史，C只复制；可选“复制即记录”且幂等 | 保持历史为有效操作而非噪声 |
| 取色软件外 vs Viewer图片 | 必须分两种后端，屏幕合成RGB/源图片RGBA分开 | 精度、透明度要求不同 |
| 精确捕获HDR/DRM | 尽力支持+明确技术限制，不承诺绕过保护 | Windows能力与用户安全边界 |
| 第三方插件参考代码 | 仅研究，不直接复制未知授权构建代码/色库 | 尊重版权，避免许可证冲突 |
| 是否版本名递增 | 不擅自改变主应用版本，依真实现有tag/RC策略 | 保持项目发布规范 |
| 测试真实执行状态 | 新包中全部为NOT_RUN，不能把设计用例写成通过 | 资料完整不代表软件实现与测试成功 |
