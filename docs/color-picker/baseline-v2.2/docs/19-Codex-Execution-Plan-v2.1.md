## 三、开发里程碑
- `M0` 快照当前可用功能，建立编译基线和截图基线，明确 PSD 当前支持范围。
- `M1` 清理轻工具中间菜单；底部竖向翻转后增加吸管；取色、快捷键与老工具栏不回归。
- `M2` 旋转/镜像分离视图记忆与导出副本；实现可点击非模态 toast，兼容旧 RotationStore。
- `M3` PSD/PSB 能力检测、图层树/通道/缩略图/状态化面板；原始合成始终可信。
- `M4` 真正的显隐重合成（基本层、组级），失败回退、会话恢复；逐类扩大对复杂混合模式/蒙版/颜色模式的支持，真实比对 Photoshop 基线。
- `M5` 所有 v2.0 颜色助手功能按原既定路线实现，AI 最后。完成全部回归和发布审核。

## 四、验收禁止事项
- 禁止“图层眼睛切换成功但画面不变”，或以“继续显示上一帧”伪装成功。
- 禁止把“已记住旋转方向”描述为“已保存图片”。
- 禁止图层面板覆盖普通图片体验或常驻浮层。
- 禁止擅自从正式测试登记表减少原 259 个 Case；新增 144 个必须并入总表，去重保持 403 个唯一 ID。
- 禁止在未执行真实构建和测试的情况下标记 PASS；所有新增项初始 NOT_RUN。
- 禁止把开源 PhotoCraft 源码未经审核直接粘进工程；许可证、NOTICE、第三方依赖与发布归属同步更新。
- 禁止改变 v2.0 需求范围：历史、调色、色卡、图片提色、传统色、渐变、收藏等必须持续开发。
