## 实施设计的硬性约束

- 不能改变现有 `YeImageViewer.db` 4096 字节布局；任何序列化 schema 扩展须有迁移回归；三语言简中、英文、繁中同步；白/黑/跟随系统主题。
- `ShortcutConfig::Action` 存储索引稳定，新动作追加并版本迁移；**Ctrl+S 在远端 main 当前是 `ExportFrames`**，未经冲突处理不能抢键。
- `runTests.ps1` 当前 `28MB` EXE 门禁、SVG 图标清单、固定基准 toolbar 几何、真实窗口热区等均需更新与复测，不能删除断言掩盖问题。
- 无层普通图片绝不因 PSD 面板路径变慢；PSD 快速合成图先显示，图层数据按需后台展开，UI 线程不做重型同步解码；失败保留原始可信合成而不是伪装成功。
- 不能以编译成功等同图层绘制成功；每次开关必须实际改变正确像素，失败 UI 与像素一同回滚。
- 图片取色读取源像素 vs 屏幕取色读取屏幕显示色，提供显式切换，不可混为一个精度承诺；DPI/跨屏、HDR、Alpha 和色彩模型测试按旧包执行。
- 真正源文件写回与可逆预览要区分；优先导出副本，不覆盖 PSD/PSB 原文件；所有的“保存成功”必须文件落地后再报告。
- PhotoCraft 可参考其 BSD/MIT/Apache 以外的实质模块时，必须逐文件审计许可证/NOTICE/品牌资源；尤其关注 Rust-C++ FFI、构建、运行内存、包体与 GPLv3 发布兼容。
- 不要改变用户已存在其他功能：图片切换、惯性/12 档拖拽、连续阅读、图片缓存、RAW/ICC、缩略图、触控与窗口形态回归。
