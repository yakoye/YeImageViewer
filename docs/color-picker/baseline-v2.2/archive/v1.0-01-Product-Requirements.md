# YeImageViewer 取色器与颜色助手 — 产品需求文档（PRD）

- 文档版本：1.0（2026-10-20）
- 产品：YeImageViewer（Windows）
- 功能代号：Color Picker / Color Assistant
- 状态：开发需求基线；尚未根据源码确定技术栈和实际应用版本号
- 目的：供 Codex/其他开发 AI 直接拆解实现，不要求逐像素复刻第三方产品
- 原则：原有图片查看功能零回归、取色器轻量快速、颜色助手可独立打开、所有核心颜色计算离线可用

## 1. 目标与非目标

### 1.1 必达目标

1. 在 YeImageViewer 内一键取色；也可在所有普通桌面窗口上方对**当前 Windows 桌面全部显示器**进行取色。
2. 有精确到单个物理像素的放大镜，支持越界自适应，明确坐标系。
3. 复制 HEX/RGB/HSL/HSV 等格式，取色后可选择只复制/留在当前图片/打开颜色助手。
4. 颜色助手含颜色编辑、推荐配色、UI 色库、传统色、渐变、图片色卡、收藏，具有统一当前选中颜色状态。
5. 支持深色、浅色、跟随系统主题；支持键盘与鼠标操作；离线可用。
6. 多显示器/混合 DPI/不同缩放/负坐标/显示器热插拔/远程桌面具备可验证行为。
7. 新增代码与文档、测试、缺陷跟踪、变更记录同版本维护。

### 1.2 不做隐式承诺

- 不保证捕获 DRM 保护的视频、Windows 安全桌面、UAC 安全提示或禁止截屏的应用。
- 不把屏幕 RGB 计算得到的 CMYK 当成印刷色彩管理或 ICC 分色结果。
- 不承诺 HDR、广色域屏幕与所有 ICC 配置下能直接获得未经映射的原始光学值；需要明确取样模式与色域限制。
- “AI 配色”可作为独立阶段；基础配色不能依赖云端或付费 AI。

## 2. 产品入口与整体流程

### 2.1 入口

- 图片工具栏：增加吸管图标；与现有缩放、拖拽等图标一致，提示“取色”。
- 菜单：工具 → 屏幕取色、图片取色、颜色助手。
- 主窗口内快捷键：提供用户可配置快捷键；**不得覆盖现有 YeImageViewer 快捷键**，只有无冲突才启用推荐值。
- 全局热键：默认关闭，用户显式启用后注册；冲突时提示并可更改，禁用时完全解除注册。
- 颜色助手窗口本身有屏幕取色按钮，可重新选色。

### 2.2 三条主要路径

**A. 快速屏幕取色**：调用取色器 → 多显示器全桌面覆盖 → 悬停放大与预览 → 左键选定 → 按设置复制值 → 不弹大型助手（默认）。

**B. 查看当前图片像素**：调用图片取色 → 基于图片图像坐标采样 → 取样原始像素 RGBA → 颜色值/坐标预览 → 复制，或“在颜色助手中查看”。

**C. 颜色研究**：直接打开颜色助手，或由已经取得的颜色打开 → 色轮手动调节 / 修改输入 / 选色卡 / 选渐变 / 图片提色 / 收藏 / 导出。

默认最后一次颜色和页面可以恢复，但不能因此改变当前图像、缩放和滚动位置。

## 3. 模块 A：全桌面屏幕取色器

### 3.1 最小型取色 HUD（图 1）

展示以下信息：

1. **像素放大区**：按 15×15、17×17 或 21×21 的奇数方格显示采样区域（默认 15×15，可选），每格清晰分隔；中心像素高亮蓝色十字准星与边框；不能用抗锯齿模糊像素。
2. **当前位置坐标**：如 `(1067, 811)`；允许负值；提示当前模式“屏幕绝对 / 显示器相对 / 图片像素”。
3. **当前颜色**：实色小色块、颜色文本，如 `#FFFFFF`；以所选格式实时刷新。
4. **快捷键提示**：`Shift` 切换格式（可配置）、`P` 切换坐标、`C` 复制色值；显示在放大区下方而不是遮住中心像素。
5. **更多快捷键**：`Enter` 确认/复制、`Esc` 取消、方向键细移、`Space` 冻结/恢复；可在按 `?` 时弹出帮助，不必在默认 HUD 中全部显示。
6. 高对比可读样式；深浅背景自动选择文本颜色；界面可随 Windows DPI 放大，**像素采样仍以物理像素为基准**。
7. 取色时可选显示当前像素 RGB、坐标系统、所属显示器编号；默认紧凑，扩展信息通过设置开启。

### 3.2 指针与放大镜行为

- 在光标附近跟随，不能遮盖系统光标或样本点；推荐偏移 18–30 DIP。
- 临近各显示器的上、下、左、右边界时：HUD 自动上下/左右翻转，保持完整显示在**光标所在显示器的可见边界**内；不足以容纳时固定在该屏可显示位置。
- 显示器左侧为负坐标、上侧为负坐标均能正常取样。
- 中心像素用清楚的 1px 边框（输出乘以显示倍率）；十字高亮不能被采进颜色结果。
- 采样区域在屏幕外的点以透明棋盘格或灰格标记，不复制不存在的像素；中心光标若仍位于有效屏幕内则可取色。
- 跟随操作要低延迟；重复按方向键移动取样十字而不强制移动鼠标也可以（建议内部游标位置）。
- 采样 HUD 出现前先捕获源图；避免 HUD、遮罩或按钮颜色成为被采样的像素。
- 采样颜色“所见即所得”：屏幕取色读取该时刻桌面合成帧的 RGB；不同于图像内部原始 RGBA。

### 3.3 坐标模式

| 模式 | 基准与定义 | 例子 |
|---|---|---|
| 屏幕绝对坐标（默认） | Windows 虚拟桌面的**物理像素**坐标；主屏幕左上角通常是 (0,0)，其他屏幕可为负 | `屏幕 (-640, 500)` |
| 当前显示器相对坐标 | 光标所在显示器左上角是 (0,0)，以该屏物理像素计 | `显示器2 (280,500)` |
| 图片原始像素坐标 | 仅图片取色时出现；解码后的图像像素，以左上角 (0,0) 开始 | `图片 (1224,807)` |
| 可选 UI 逻辑坐标 | 仅供调试：DIP/Windows 缩放后逻辑坐标；必须标注单位，不与物理像素混淆 | `逻辑 (..,..)` |

快捷键 `P` 在当前可用模式之间循环；HUD 中立即显示模式名。坐标与颜色复制可以独立操作，可配置复制包含坐标还是只包含颜色值。

### 3.4 色值格式与复制

**至少支持**：

| 名称 | 示例格式 | 规范 |
|---|---|---|
| HEX | `#53CAA4` | 默认六位大写；可选小写、去 `#` |
| HEX8（图片模式） | `#53CAA4FF` | 含 alpha，注明 RGBA 顺序 |
| RGB | `rgb(83, 202, 164)` | 8-bit 整数通道 |
| RGBA（图片模式） | `rgba(83, 202, 164, 1.00)` | alpha 单独换算 |
| HSV/HSB | `hsv(160.84, 58.91%, 79.22%)` | 色相 [0,360)，饱和/明度 [0,100%] |
| HSL | `hsl(160.84, 52.89%, 55.88%)` | 色相 [0,360)，S/L 百分数 |
| CMYK | `cmyk(59%, 0%, 19%, 21%)` | 从 RGB 的近似换算，显著注明非印刷分色 |
| CIE-L*a*b* | `Lab(74.03, -42.48, 9.08)` | 指明 sRGB → D65 → CIELAB 标准与范围 |
| HSI | `hsi(161.78, 44.54%, 58.69%)` | 采用文档化算法，H/S/I 与 HSV 区分 |

- 快捷键 Shift 切换当前 HUD 复制格式，**必须避开图像编辑中的 Shift 功能**；也提供下拉菜单选择和设置项调整。可配置循环列表，默认只循环 HEX→RGB→HSL→HSV（高级格式在设置里加入）。
- `C`/`Ctrl+C` 将当前显示格式复制到系统剪贴板；复制成功短提示“已复制 #53CAA4”，失败明确提示；避免在全局模式拦截其他应用输入。
- 左键确认默认：复制色值 + 退出 HUD；可配置“只选定”“复制后仍继续取色”“选定后打开颜色助手”。
- 右键默认取消；菜单右键功能与取色右键取消应在模式退出时恢复原样。
- 可选：“复制纯值 / CSS 代码 / HEX+坐标 / RGB+坐标 / JSON 颜色对象”；一键复制调色板。
- 失败不能复制上一个颜色当作当前颜色；应保留“当前取色失败”状态。

### 3.5 取色状态机

`Idle → PreparingCapture → PickingLive/Frozen → Selected/Cancelled/Error → Idle`

- `PreparingCapture`：隐藏会污染采样的自身控件；获取源画面并确定显示器拓扑。
- `PickingLive`：光标更新当前候选像素，HUD 显示、键盘可操作。
- `Frozen`：冻结最近一次采集的源帧，方向键可微调；在仅支持快照的环境中应明确提示已经是静态快照；恢复实时失败不应误取过期帧。
- `Selected`：保存颜色记录、复制（若开启）、退出覆盖层并按规则返回。
- `Cancelled`：不修改当前选中颜色，不影响图片阅读状态。
- `Error`：源画面不可用、显示器移除或截屏被阻止时显示安全错误，不使用过时的伪造像素。
- 保证异常关闭后释放顶层窗口、鼠标/键盘捕获、热键、截图资源。

## 4. 模块 B：图片原始像素取色

- 直接利用 YeImageViewer 的图像解码后像素，不通过屏幕截屏得到颜色；支持无缩放、缩放、旋转、镜像、平移后的“视图 → 原图像素”逆变换。
- 对图像以最近邻对应**单个源像素**取色，不对屏幕双线性缩放后的混合色误判为原像素；提供“显示颜色模式”作为可选附加能力，并且明确标注。
- 单张 PNG/JPEG/BMP/WebP/GIF/TIFF 等，具体文件类型遵循项目当前已支持范围。GIF/动图应明确抽当前显示帧；如有色彩管理需注明已转换或原始颜色空间。
- 带透明通道图片：读取原始 RGBA 和 Alpha；全透明但 RGB 非零的像素也可以显示原始通道值；在棋盘背景上的合成显示结果单独标注。
- 非图像区域显示“图像外”而不是读取窗口底色；图像旋转边界正确处理。
- 同屏 HUD 同一组件复用样式和通用键位；`P` 可切换图片原始坐标、当前显示区域相对坐标（可选），但不与屏幕绝对坐标混淆。
- 图片查看过程中启用取色，退出必须恢复原来的工具、鼠标形态、拖拽行为、焦点、滚动位置、缩放倍率、当前图片索引。

## 5. 模块 C：颜色助手主界面

### 5.1 外观与导航（图 2–7）

- 独立的模型无关工作台窗口，可从主程序多次打开但避免重复创建无关实例（单工作台可复用）。
- 左侧导航建议 7 项：**颜色 / AI 配色 / UI 色卡 / 图片色卡 / 传统色 / 渐变色 / 收藏颜色**。
- 常用操作顶部展示“吸管重新取色”“当前颜色”“撤销颜色更改”（可选）；选取一项后各页面同步同一个当前颜色状态。
- 顶部页签和侧栏样式参考截图的布局，但使用 YeImageViewer 自有名称和图标。
- 初始窗口建议约 1000×750 DIP，提供最小宽高与自适应布局；小窗口时侧栏可收起、右侧属性面板可切换为下方分页，避免裁切。
- 三态主题：浅色 / 深色 / 跟随系统；键盘导航、焦点框、可访问性标签；中英文预留本地化（默认中文）。

### 5.2 “颜色”页面（图 2/3）

**布局**：左侧色轮 + 底部至少两条调节滑块，右侧推荐配色 + 多格式数值编辑与复制。

- 色轮：鼠标点击/拖拽可选取任意色相与饱和度；按截图样式可实现 hue wheel 或 HSV color disk。中心亮度/白化行为必须跟数值算法一致，避免“看到的颜色 != 读出的颜色”。
- 两条滑块：至少 `明度/亮度`、`深浅/黑白` 可调；建议以 HSV V + alpha（仅图片）或 HSL L 的清晰标注替代无标签滑块；不要让两条滑块语义重叠。
- 右侧字段：HEX、RGB、HSV/HSB、HSL、CMYK、HSI、CIE-LAB；每行可复制，支持输入合理格式并实时解析更新颜色与色轮；失效输入保留待修正，不能污染当前颜色。
- HEX 编辑支持有/无井号（设置/复选框），大小写标准化；剪贴板文本解析 `#RGB`、`#RRGGBB`、`rgb(...)`、`hsl(...)`（根据精度实现）。
- 推荐色组（按截图）：互补色、类似色、对比色、中差色。选中的色块有描边/检查标记，鼠标停留显示 HEX 与色值；点击更新当前颜色，右键复制色值/收藏。
- 配色计算采用定义明确的 hue 角算法，数值可验证，不要直接写死截图中的推荐颜色。建议：互补色 = h+180°；类似色 = h±30°；分裂互补/对比色 = h±150° 或提供明确模式；中差色 = h±90°。名称、角度均应在帮助中给出，可配置。
- 增加**文本可读性/对比度工具**（建议 P2）：输入前景/背景，显示 WCAG 对比度比值和 AA/AAA 结果（按相应尺寸），不把“互补色”等同于满足可读性。

### 5.3 “AI 配色”页面

- 不影响基础离线配色功能。分为“**智能规则配色（离线）**”和“AI 自然语言配色（可选）”。
- 离线模式提供：单色、邻近、互补、分裂互补、三角色、四方色、同色系、冷暖、低饱和、暗色方案；输出 4～8 色，带主色/辅助色/背景色/文字色/强调色角色，实时预览简易 UI。
- 可选 AI：输入“自然、科技感、适合深色界面”等文字建议；清楚提示是否联网、是否上传当前图片/颜色，并提供明确授权；未配置 API 不得报错破坏主功能。
- 输出方案可复制 CSS 变量、JSON、导入收藏；保留配色来源（规则/AI）和编辑记录。

### 5.4 “UI 色卡”页面（图 4）

- UI 色库导航参考 Flat UI、Fluent Design、Open Color、Ant Design、Material Design 等。**先核验每套公开颜色数据的官方来源与授权再内置**。
- 列表提供系列、主题、色阶、名称、HEX、复制；单击选色，双击复制可设置，右键收藏。
- 模式：表格网格/色阶条；可筛选名称、色相、深浅、系列。支持明暗主题预览。
- 截图中“默认、中国、美国、澳大利亚”等分类可作为自定义调色板标签，不应误写成上述 UI 框架的官方标准。
- 颜色数据由单独的版本化 JSON/CSV 文件驱动，UI 不内嵌大量硬编码。

### 5.5 “图片色卡”页面

- 图片来源：当前 YeImageViewer 正在显示的图片（最优先）、打开本地文件、粘贴剪贴板图片、拖入图片。
- 自动提取主色：选择 3/5/8/12 色，默认 6 色；支持 K-Means 或 Median Cut、近似色合并、忽略几乎透明像素、极暗/极亮噪声过滤。
- 展示色卡 + 占比 + HEX；点击应用颜色，复制单色/全套色卡，收藏、导出 PNG 调色板预览和 JSON/CSS。
- 允许手动框选区域提色，以及指定“细节优先 / 面积优先”；图像算法在后台运行，取消/换图时安全中断，无卡死。
- 分辨率大于正常大小的大图采用下采样和限制像素预算，不触发全量图片重复复制；保存来源仅在用户明确要求时存储文件路径。

### 5.6 “传统色”页面（图 5）

- 至少两个分类：中国传统色（可按节气、主题筛选），日本传统色（可按名称/色相筛选）。
- 每个色块显示中文名（必要时日文/罗马音）、HEX、颜色背景；根据亮度自动决定字体颜色。
- 搜索：中/日文名、拼音、HEX、分类；顶部色相筛选（红/橙/黄/绿/蓝/青/紫/灰等）。
- 能复制色号、收藏、定位到色轮；支持详情展示典籍来源/色名含义，但仅在数据有可靠出处时显示，不生成未经核验的历史说明。
- 参考截图的“立春/雨水”分组与色块网格，支持虚拟滚动；数据来源与授权独立维护，不承诺复制第三方专有色库。

### 5.7 “渐变色”页面（图 6）

- 以卡片展示渐变预设，支持 2～4 个色标和预览条。每卡显示两个端点/多个色标缩略色。
- 分类筛选颜色（顶部色点）、渐变方向、热门/最新/自定义；可以搜索颜色 HEX。
- 点击查看完整参数；支持修改色标、插入/删除节点、角度、线性/径向渐变；默认至少实现线性 2 色。
- 一键复制 CSS，如 `linear-gradient(90deg, #53CAA4 0%, #0074D9 100%)`；可导出图片或 CSS/JSON；收藏自定义渐变。
- 渐变内插算法必须注明 sRGB 或 OKLab；默认 sRGB 与浏览器 CSS 展示更接近，可提供 OKLab 平滑模式作为后续增强。

### 5.8 “收藏颜色”页面（图 7）

- 空状态文字“暂无收藏颜色”，右下角主按钮 `+` 支持手工新增。
- 收藏内容支持纯色、渐变、调色板；包含颜色值、名称、标签、来源、创建/修改时间、备注。
- 支持复制、编辑名称、排序、搜索、标签、删除（可撤销，避免误删）；重复颜色要允许用户选择“合并/保留不同备注”。
- 持久化到用户目录下配置文件，不需要账号联网；重启后可恢复；支持 JSON 导入导出，必要时支持 CSS/TXT 输出。
- 数据写入采用临时文件 + 原子替换 + 校验/备份；损坏文件不得使查看器崩溃，提供恢复或重建提示。

### 5.9 “颜色历史”与统一操作

- 建议提供历史页签或顶部最近颜色条（默认最近 50 个，可配置），历史和收藏分开。
- 主窗口/取色器/颜色助手之间仅维护一份 `CurrentColor` 数据状态；原色不变时页面导航不能无意修改它。
- 每次操作定义“预览”与“确认”：悬停只预览、点击才提交到历史；记录来源（屏幕/图片/色轮/传统色/渐变）。
- 允许复制与收藏，不强制每次打开颜色助手。

## 7. 设计与交互规范

- 维持现有 YeImageViewer 视觉语言，不直接复制第三方产品名称、商标或整套像素样式。
- 所有图标统一规格，视觉尺寸与工具栏现有图标一致；颜色值使用等宽数字更利于比较。
- 输入框提供合法范围、即时预览、无效输入提示、无障碍键盘焦点；滚轮可以微调可编辑数值，但不能意外改变滚动图片。
- `C`、`P`、`Shift` 仅当取色器拥有焦点时使用；全局热键默认关闭。
- 彩色背景上的文本依据对比度选择深/浅；选中色块不能仅靠颜色区分，增加边框/对勾。
- 切换主题不破坏已有颜色、搜索、选择、焦点，主题生效无需重启。
- 大窗高 DPI 自适应，侧栏溢出滚动，100% 与 200% 下不截断按钮。

## 8. 非功能要求与性能目标（测量，不硬编码机器结果）

- 取色 HUD 启动、鼠标移动与复制须流畅；建议目标在典型 Windows 工作站上启动可感知延迟 < 300ms，跟随刷新≥30fps，持续取色无明显 CPU/GPU 异常占用；实测结果记录机器信息。
- 多屏幕截图不应每鼠标移动都拷贝整张大画面到 CPU；按需缓存每显示器帧/采样区域。
- 超大图片提色应异步进行，可取消、可退出，内存有界。
- 取色器/助手异常不能阻止主程序退出；程序退出后无残留透明挡鼠标窗口。
- 无网络也可正常使用取色、色轮、颜色转换、色库（本地已装）、传统色、渐变和收藏。
- 存储最少数据，不能在后台悄悄上传屏幕截图、图像内容或历史颜色。

## 9. 分阶段迭代（功能代号，不擅自改变现有软件版本）

| 阶段 | 交付范围 | 验收门槛 |
|---|---|---|
| P0 — 屏幕取色 MVP | 入口、全桌面抓取、像素 HUD、边界自动翻转、坐标、HEX/RGB/HSL/HSV、复制、取消、设置、多屏+DPI | 通过 P0 关键自动/手工测试，主图片查看流程无回归 |
| P1 — 图片取色与色轮工作台 | 图片原像素 RGBA、主工作台、色轮、数值输入/复制、配色算法、历史、收藏 | RGB↔HSL/HSV/HEX 往返误差在定义公差内、收藏持久化 |
| P2 — 丰富色卡 | UI 色卡、传统色、渐变、图片色卡；JSON/CSS 导出 | 数据授权核验、提色性能、导出兼容 |
| P3 — 高级增强 | 离线配色模板、对比度工具、AI 插件接口（可选）、HDR/广色域深入兼容、增强可访问性 | 进阶功能不会影响 P0/P1/P2 核心可靠性 |

P0 / P1 / P2 每个阶段均必须真实编译、真实运行验证，不能把未运行的测试标为通过；若当前版本是 rc，修复失败时继续在同一 rc 系列递增，不因 bug 未解决而直接升正式版本。

## 10. 最终验收场景（用户语言）

1. 我在 YeImageViewer 里按吸管，移动到另一个显示器上的浏览器，屏幕取色仍准确，左键一次复制 HEX 后退出。
2. 光标移到屏幕任意角落，放大镜始终完整可见；负坐标也正确。
3. 我按 P 在屏幕绝对/显示器相对坐标间切换，按 Shift 切换 HEX/RGB/HSL/HSV，C 复制内容正确。
4. 图片放大 2000% 并拖拽后，图片取色依然给出**原始像素**坐标/色值，而非被缩放插值污染的屏幕色。
5. 在颜色助手编辑 `#53CAA4`，色轮、RGB、HSL、HSV、LAB、推荐配色同时变化，复制值正确。
6. 我能选一个传统色/渐变、收藏、重启 YeImageViewer 后找回，并导出为 CSS/JSON。
7. 不插网线依然可使用绝大多数功能，取色期间不出现鼠标被窗口永久挡住的情况。
