# rc9 颜色页面与入口修正

用户最新指令优先于需求包中的旧入口约定：吸管左键直接屏幕快速取色，右键直接颜色面板，不弹中间菜单。图片右键的颜色工具仅保留“取色（屏幕快速取色）”与“颜色面板”；删除图片取色入口及交互，不影响PSD图层和保存副本等其他业务菜单。

后续红框反馈更新：默认客户区收紧至810×600 DIP，数值卡360DIP，默认输入栏182DIP；屏幕取色文字按钮改为44DIP圆形吸管图标，复用工具栏SVG，保留“取色”辅助名称、悬浮提示和键盘焦点。菜单/快捷键/吸管提示统一称“取色”，实际读取桌面显示像素；已经取消图片源像素取色，不混称原图RGBA。删除内部重复标题及应用/取消按钮行；即时联动，关闭保留当前色，Esc恢复原色关闭。下面原1000×680及应用/取消行方案被此项覆盖。用户又明确选择“当前修正版先打包，再分批补齐”；左侧完整导航、永久历史/收藏/各类色卡没有完成，不把本批称作完整助手。

## 实施顺序

实测补充：保留竖向滚动条时目标客户宽810DIP；默认600高度内容不溢出、系统隐藏滚动条后为827DIP。数值卡固定360、输入栏182，后续拖大窗口也不再把数值卡拉宽；没有用缩小字体来满足收窄要求。

1. 保存rc8源码与EXE基线；新增入口反例，确认旧实现不能通过新要求。
2. 清除图片取色运行状态、异步解码和命令分派；保留原菜单命令编号的空位，避免重用旧编号。
3. 按原包`fig-02-workbench.png`和`fig-03-color-wheel.png`重建“颜色”页：大圆盘（色相/饱和度）、S/V两滑杆、当前色大背景、原色/当前色对照、推荐色、右侧七行数值及逐行复制，不再用小色环与格式下拉框代替。
4. 加入原色恢复、撤销/重做、应用/取消；滑动一次仅形成一次撤销事务；无效输入不污染当前色。保持快取默认复制退出，E/面板取色回到编辑；独立启动不创建看图主窗口。
5. 白/黑主题跟随现有设置，原生编辑控件保证键盘/输入法；窄窗切换“选色/数值”视图，内容不足时滚动，不裁切七行字段。DPI变化不重建输入字段，不抹掉无效草稿。
6. 单元、生产控件、入口真窗口、完整`runTests.ps1`和解压包复验；通过后新的候选绿色包双归档，不覆盖rc8，不公开发布。

## 视觉与交互契约

- 默认客户区约1000×680 DIP；正常宽度左侧选色，右侧约400 DIP浅/深中性卡片；圆盘直径随左栏调整，不画方形SV块。
- 七行顺序：HEX、RGB、HSV/HSB、HSL、CMYK、HSI、CIE-LAB。每行可编辑，独立复制；格式共用既有转换器。Lab为D65、CMYK为数学近似，均明确说明。
- 推荐色按HSV色相偏移确定：互补+180°；类似±30°；对比±120°；中差+90°/+180°/+270°。保留当前S/V，点击应用，右键复制，避免暗中引入网络或第三方色库。
- 圆盘更改H/S，第一条滑杆S，第二条V。按下开始事务，拖动实时预览，松开提交单步Undo；取消/捕获丢失关闭事务。
- 用户在其他窗口工作时不抢焦点；独立工具可从任务栏恢复；同进程打开复用已有面板。
- 此批重建原设计的“颜色”页，不摆放无功能的历史/色卡/收藏/AI按钮；原全部页面仍保留在长期台账，不能将它们称为完成。

## 验收边界

必须保留rc8完整通过记录和本轮所有失败；入口修前反例、字段双向同步、推荐色、Undo/Redo、原色恢复、取消与跨窗口采色、浅深主题和窄窗/DPI均有独立检查。仿真DPI不代表Win10 4K200%/混合DPI/HDR实机通过。额外读屏工具如再次窗口绑定失败须明确记录，不靠换一份开发EXE冒称包内验收。
