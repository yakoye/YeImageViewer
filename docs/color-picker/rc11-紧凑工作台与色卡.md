# rc11 紧凑工作台与色卡

本次六点反馈优先于旧版可拉伸窗口设计。候选不公开发布，不覆盖rc10。

## 固定布局

- 客户区680×430 DIP，约为rc10宽高的70%；去掉调整边框和最大化，不接受系统拉伸。DPI切换重新按逻辑尺寸计算，不能拉伸旧画布；字体12 DIP（原14）。
- 左侧96 DIP，顺序：颜色、取色历史、色卡、传统色、渐变色、图片色卡、收藏颜色。沿用旧页码保存历史/收藏，不因重排改掉用户页面。
- 色盘背景224 DIP，圆盘200 DIP；右卡片固定宽度，七行及复制控件全部显示，不再进入窄屏分页。小工作区按统一比例缩小整个内容并保留逻辑布局，避免只裁切按钮。
- 去掉记录颜色/收藏当前色两个导航按钮。色盘右上角星形收藏按钮，辅助名称“收藏颜色”。吸管替换为Phosphor regular eyedropper，上游路径和MIT声明随包保留。
- 右下方近期历史为多行色块，行优先、从左到右、最新在前；点击回到该颜色，右键复制HEX；完整历史仍走历史页。无记录时显示空状态，不用预置色冒充用户历史。

## 记录时机的本次变更

删除显式记录按钮后，以完成一次有效颜色操作为提交：色盘/滑杆松开、有效字段失焦或Enter、选择推荐色/色卡。拖动中间值、无效字段、取消捕获、历史回看不新增。HUD确认仍只记一次；复制默认不记，收藏本身不记。失败有提示，绝不假称记录成功。

## 色卡实际功能

本批提供可操作的离线色库网格/搜索/分类/复制/应用/单色收藏；传统色保留名称与近似RGB，不编造历史出处。用户随后明确允许处理所供参考包数据库，因此导入其中静态数据，保留来源/哈希，不执行脚本；公开再分发许可另行确认。1911条色卡、377条2～4色标渐变；参考Material的空占位不伪造颜色，#FFF按规则规范为#FFFFFF，5条超过4色标渐变不截断导入。

渐变提供真实sRGB插值预览、2～4色标、线性/径向、角度及CSS复制；图片色卡提供本地导入/拖入/剪贴板及有界异步提色、数量选择、占比、复制及单色收藏。图片色卡是整图主色提取，不恢复已取消的原像素吸管入口。

完整方案中的所有框架色库、节气人工考据、任意区域框选、调色板/渐变收藏及多格式导入导出若尚未实现，必须继续列缺口；不以本批基础功能将全部原设计打PASS。
