- 43.psd根行有“组3”（实际为像素层）、“组2”（文件夹）、带蒙版的“0”、普通层和锁定背景；名字带“组”不代表分组，必须按真实类型判断。

## 当前YeImageViewer已核对的差距

1. PsdDock只对名称按depth缩进8DIP；展开三角/缩略图固定在44DIP，没有文件夹树列，点击仍固定70DIP界限。嵌套组视觉和热区没有统一几何。
2. 旧侧栏自检夹具只有三个平铺图层，验证开关、恢复、通道及DPI离屏绘制，**没有**验证嵌套组的折叠/列对齐/点击热区，没有拿真实43.psd作设计验收。
3. 60项PSD/PSB测试证明保存合成图的解码正确，不证明临时重合成与PhotoCraft/Photoshop能力相同。
4. 现有重合成主要限定8位RGB；这两份真实文件是CMYK/8，不能把其“原始合成可显示”当作图层开关完整支持。必须事前标明只读/具体限制，不能让用户点击后才发现没有实现。
5. 当前通道只是显示RGB/Alpha，尚非CMYK原生通道；层属性、蒙版/智能对象/效果标识、长名称提示和键盘树导航也未达到原设计。
