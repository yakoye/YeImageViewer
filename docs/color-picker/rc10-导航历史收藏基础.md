# rc10：导航、永久历史与单色收藏基础

日期：2026-10-21。状态：开发验收中，不公开发布。遵循[存储与事件决策](ADR-002-永久历史与收藏.md)，只交付这批实际功能，不称完整颜色助手。

## 界面和操作

- 左侧136DIP导航：颜色、取色历史、收藏颜色。默认内容区在rc9基础上只增加导航宽度，原数值卡360、输入182DIP不变；最小窗口720×460，系统工作区小于该值时按工作区限制。历史来源/日期控件在较窄窗口换行，不隐藏过滤条件。
- 颜色页的“记录颜色”明确记录当前色，“收藏当前色”建立单色收藏。普通调色、关闭窗口不会偷偷记历史；不恢复被用户取消的应用/取消行。
- 历史最新在前，每页100条；支持HEX大小写搜索、UTC起止日期、屏幕/编辑来源过滤、复制HEX、再编辑、删除及收藏。显示UTC并明确标注，坐标若启用为屏幕绝对物理坐标。
- 收藏支持名称80字、标签160字、HEX修改，上移/下移排序、搜索、复制/回到色轮编辑、删除。单色收藏不等于渐变/调色板收藏。
- 历史容量100/500/1000/5000/无限，默认1000；HUD“C复制即记录”和保存坐标默认关闭。历史复制永远不新增历史。切换导航页和数据跨重启保留；当前预览颜色仍仅在进程内共享。
- 删除与清空均再次确认，默认取消；清历史不清收藏。备份以时间戳命名保留旧份；恢复选择颜色数据目录内最新备份，先校验并询问。当前原库以及旧事务日志另存，活动连接存在时拒绝替换。
- 空结果显示明确说明；输入无效、数据库只读/损坏/未知schema、保存失败均不报告成功，不默默清空数据。取色确认历史失败保留HUD供重试/取消，已复制与未保存分别说明。

## 数据

默认保存到系统LocalAppData目录下`YeImageViewer/ColorAssistant/colors.sqlite`；使用系统SQLite，不增加随包DLL。无截图/窗口名/进程名/原图路径，默认无坐标。测试通过`YEIMAGEVIEWER_COLOR_DATA_DIR`隔离；包不带测试库或开发配置。看图原DB完全不变。

数据库schema1，历史与收藏分表；事务保证原子写入、唯一确认事件键去重，UTC毫秒时间；同色不同确认保留。父记录删除/容量裁剪后关联置零，避免悬挂引用。SQLite备份API制作一致性快照；显式恢复原库保留，版本或校验失败拒绝替换。
