- 原始259表不改状态；每批在 artifacts 生成独立执行登记，保留失败日志。
- 本批七个编号的自动 PASS 仅覆盖当前单屏的对应完整场景；16个硬件/受保护桌面场景 BLOCKED，236个 NOT_RUN（包含未完整实现及仅覆盖子项）。这不等于完整 P0 通过。
