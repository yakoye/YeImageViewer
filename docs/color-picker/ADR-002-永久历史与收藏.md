# ADR-002：永久历史与收藏

状态：接受，实施中。日期：2026-10-21。范围：rc10下一批导航、历史和单色收藏，不包含完整色库、渐变、AI或图层转换。

## 决策

复用原生颜色面板，左侧增加实际可用的颜色/历史/收藏导航。工作页保持rc9的紧凑字段，不恢复应用/取消行。历史页明确显示记录、搜索、来源/日期筛选、复制、编辑、删除；收藏支持名称/标签、改色及排序。

数据使用Windows系统目录中的winsqlite3.dll，经LoadLibraryExW限定SYSTEM32加载。缺库时明确失败，不加载同目录同名DLL。SQLite事务和唯一eventKey解决多进程写入与重复确认；不用整份JSON读改写，以免并发覆盖。数据库默认位于LocalAppData/YeImageViewer/ColorAssistant，测试通过专门环境变量隔离。看图YeImageViewer.db的4096字节及文本区均不改。

只保存RGBA、UTC时间、screen/editor来源、可选坐标、父记录ID及用户输入标签。默认不保存坐标，不保存截图、图名、窗口名、进程名。历史和收藏分表，清理历史不清收藏。容量100/500/1000/5000/无限，默认1000。SQL预编译绑定所有外部值，版本不匹配拒绝写入。操作失败不伪称已保存。

## 确认事件契约

- HUD左键/Enter确认：记录一次；C复制默认不记录，设置开启后按逻辑动作生成独立事件key；关闭/取消不记录。
- 送回颜色面板、拖色轮/滑杆、字段输入、切推荐色、窗口关闭：仅预览，不自动记历史。
- 颜色页新增明确“记录颜色”按钮，不叫应用，也不关闭窗口。再次编辑后记录可建立parentRecordId；同一确认重试使用同一key。
- 历史的复制、再编辑、删除、搜索不会新增记录；单色收藏也不自动入历史。
- 取色历史失败时，HUD仍留在原会话，显示重试/取消提示；剪贴板成功与历史保存失败分别说明。

## 备份与恢复

SQLite事务负责崩溃一致性；提供显式创建备份及恢复备份操作，使用SQLite在线备份API，不直接复制正在使用的数据库。恢复为明确用户动作，先校验备份schema/integrity，失败不覆盖当前数据。损坏数据保留原文件并给出错误，不自动清空或冒称恢复。备份含历史和收藏，设置单独说明。

参考：[SQLite备份API](https://www.sqlite.org/backup.html)、[SQLite事务错误码](https://www.sqlite.org/rescode.html)。

## 验收

纯存储验证边界/去重/parent/筛选/容量/标签/只读/损坏/未知版本/备份恢复；真子进程并发验证无丢失；实际窗口验证导航/跨重启/复制不污染历史/取消/单色收藏/键盘/主题/DPI。所有新测试加入runTests；最终完整绿色包与双归档，不公开发布。未覆盖的原259/457条保留未完成，不批量标PASS。
