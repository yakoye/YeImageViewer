# 取色HUD：紧凑层级与说明开关

根据2026-10-21最新两张截图调整，本批不扩展颜色助手/图层功能。

- 默认宽180DIP（原250），内边距8DIP；仍尊重用户主动选择的更大放大镜网格/倍率，不强制裁小。超长色值和坐标完整换行，不省略、不改变复制内容。
- 坐标与当前颜色：13DIP、半粗体，使用主文本色；颜色值可沿用强调色。两行各至少21DIP，换行按原生字体量高。
- 快捷键说明：11DIP、正常字重、次要文字色，行高17DIP。浅深主题保持可读，不以透明度降低整个浮层。
- F2取色偏好增加“显示取色快捷键说明”，默认开启。关闭后隐藏红框内帮助，不隐藏放大镜、坐标、颜色值，也不禁用任何快捷键；错误/复制状态仍可见。立即重排高度，跨重启记住。
- 独立INI升级v3；v1/v2读入时默认显示说明并保留原格式、网格、倍率、相对坐标、网格和准星；不修改4096字节看图数据库。
