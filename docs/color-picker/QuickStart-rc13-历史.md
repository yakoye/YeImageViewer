## 色卡与渐变

- 色卡包含Open Color、Flat UI、Fluent Design、Ant Design、Material Design，支持系列筛选、色名/HEX搜索、分页网格，点击选色、双击复制及单色收藏。
- 传统色有中国/日本分类，可按色名、HEX或“立春”等节气关键词搜索。本批1911条颜色包含不同来源近似值，同名不保证相同RGB；参考包分组不是独立考据的历史事实。
- 渐变有4个基础预设及377条参考数据，可编辑2～4个等距HEX色标、0～360°角度、线性/径向，真实sRGB插值并复制CSS。尚无透明色标、任意位置节点或渐变收藏。
- 图片色卡可本地导入、拖入、粘贴位图，或在看图主窗打开面板后使用当前图片；3/5/6/8/12色，按占比排序，可选色/复制/单色收藏。只是整图主色提取，不恢复原像素吸管。
- 文件导入走Windows WIC，具体格式取决于系统解码器，不等同查看器全部格式；可先在看图主窗打开再用当前图片。首帧缩略像素、最多256×256提色，文件限制2亿像素，剪贴板位图1600万像素。后台读取可取消/离页丢弃旧结果；当前任务结束后才接受新文件。
- 许可、固定源提交及用户参考包数据哈希见随包THIRD_PARTY_NOTICES.md。参考包静态数据由用户本次明确同意本地处理；不执行参考脚本，不据此宣称取得第三方公开再分发授权，公开发布前另行核对。

颜色数据默认位于系统LocalAppData下`YeImageViewer/ColorAssistant/colors.sqlite`，与程序目录的看图DB和取色偏好分开；换候选后历史仍在。新工作页存加法workspace表，旧prefs页码保持0～2，不破坏rc10读取。历史清空不清收藏，删除需确认；备份有时间戳且保留旧份，恢复保留原库。无限仍有64MiB预算。尚无JSON/CSV互通、删除撤销或调色板/渐变收藏，不称完整助手。

Esc恢复的是当前预览色，不会撤销已经明确保存的历史/收藏。删除属于数据库逻辑删除，不承诺文件系统安全擦除；清历史也不会删除用户保留的备份及恢复前原库。备份包含开启过的坐标数据，请按自己的隐私需要保管和清理。

本批补齐取色/颜色面板入口、当前颜色联动与历史/收藏基础，**不是完整颜色助手，也不是实时抓屏**。当前预览颜色仅在本进程内共享，只有明确确认的事件才进入永久历史。

## 立即试用

1. 吸管位于“上下镜像”右侧、手掌倍率左侧。左键立即进入屏幕快速取色，不再进入图片模式。
2. 吸管右键直接打开颜色面板，不弹菜单；图片区域右键的颜色工具只有“取色”和“颜色面板”，已移除图片取色。颜色面板可单独打开，不要求先取色。
3. 取色覆盖层展示启动时的桌面快照。左键/Enter复制退出，Esc/右键取消；E将当前颜色送入面板继续调整，不额外复制。面板左上角圆形吸管图标使用同一套HUD和偏好，确认后返回面板，取消保留原色。图标可键盘聚焦，有“取色”辅助名称与悬浮提示；不再显示文字大按钮。
4. 颜色页有H/S色盘、S/V双滑杆、原色/当前色对照、推荐色和七行HEX/RGB/HSV/HSL/CMYK/HSI/Lab编辑与复制，无效输入不污染颜色。拖动一次一步撤销，支持恢复原色、Ctrl+Z/Ctrl+Y及底部撤销/重做。即时联动，关闭保留当前色，Esc恢复本次原色后关闭。固定小窗不再使用窄屏分页或滚动画布；四个100%及Lab负值按原生字体量宽。Lab为D65、CMYK数学近似，不代表印刷ICC转换。
5. 解压完整包后双击“屏幕快速取色.cmd”或“颜色面板.cmd”，无需打开看图主窗口。也可运行`YeImageViewer.exe --screen-picker`或`YeImageViewer.exe --color-panel`；工具结束即退出，不默认常驻，不安装全局热键。

固定大小指客户区680×430DIP，系统标题栏/边框另计；DPI模拟不等于真实4K200%验收。

图层与通道只在PSD/PSB/PSDT成功解析到有范围和通道的实际图层记录后出现入口；普通图片、扁平文档、无效文件、超预算不显示。首次后台检测未完成时稍后重开菜单即可。切普通图片立即清除入口，不自动弹侧栏。树列表支持嵌套缩进、折叠状态、实际显隐继承及透明缩略图；CMYK/高位深、复杂效果/剪贴链等文档可能只能只读，显隐事前禁用。当前通道仍只是显示RGB/Alpha，不是Photoshop原生CMYK/专色完整实现。

| 按键 | 行为 |
|---|---|
| C / Ctrl+C | 复制当前颜色，保持 HUD；不写历史 |
| Shift | HEX → RGB → HSL → HSV/HSB → CMYK → HSI → CIE-LAB；按住不反复切换，同一时间只显示一种 |
| P | 屏幕绝对物理坐标 / 当前显示器相对物理坐标 |
| 方向键 | 移动采样点1物理像素，不强制移动系统鼠标 |
| Ctrl+方向键 | 移动10物理像素；不跨入显示器空洞 |
| 空格 / F5 | 临时隐藏所有覆盖层，重新抓取当前桌面；仍是快照模式 |
| F2 | 选择11/15/17/21格，4/6/8/10/12/16倍，网格/准星 |
| E | 将屏幕采样送入颜色面板调整，不额外复制 |

普通快捷键可在设置 → 快捷键中绑定“取色”，默认不绑定，避免覆盖既有自定义。**本批没有可配置的系统全局热键**；不取色时没有后台抓屏或常驻输入钩子。

## 设置、数据与限制

- 格数、倍率、输出格式、坐标显示、网格和准星存于程序同目录 `YeImageViewer.color-picker.ini`。下次启动恢复；保存失败会在 HUD 提示。便携迁移时一并复制这个文件即可。
- 颜色面板逐行复制会将对应格式保存到同一个INI，屏幕取色下次使用该格式；七行在面板内一直同时显示，不另存颜色值。
- 该偏好文件不存截图、所取颜色或实际坐标，不改原有`YeImageViewer.db`。个人颜色库在LocalAppData独立保存；不将本批基础页称作原完整方案全部完成。
- 屏幕输出是显示链路的RGB/SDR近似，不是源图RGBA、高位深原始通道、PSD原生CMYK/Lab或精确HDR测量；本批已按最新意见移除图片取色交互。
- rc7将默认HUD宽度收窄为250逻辑像素，去掉顶部模式说明，坐标与九条快捷说明分行显示。显示中的格式标签不作为颜色值复制；HEX/RGB/HSL/HSV沿用原复制语法。
- CMYK按RGB数学换算并取整数百分比，不代表打印机/油墨ICC结果；HSI采用等强度模型；CIE-LAB采用sRGB逆传递、D65参考白，保留三位小数，复制为`Lab-D65(...)`，不是CSS D50的`lab()`。
- 独立偏好文件升级到v2，读取v1时保留原四种格式及其他选项。建议新旧候选分目录使用；旧rc6无法识别v2偏好文件，会回到默认值，不保证降级双向兼容。
- 不绕过 Windows 安全桌面、DRM 或系统保护。GDI 成功返回的受保护黑色内容无法可靠区别于真实黑像素，因此不承诺这些区域色值可信。
- 实时取色、系统全局热键、复制附加坐标、历史高级互通、任意区域框选、渐变/调色板收藏、多种导出、规则助手和AI仍在台账内，不冒充完成；AI最后。已取消的图片原像素取色不恢复。
- 真多屏、混合 DPI、HDR、Win10 4K/200% 仍需对应硬件验收。几何模拟与当前单屏窗口回归不代替这些检查。

候选包不能覆盖已有正式版/候选，未公开发布。遇到问题可关闭本候选、使用原 rc8独立目录；原图和DB布局未改变，不要将新偏好文件覆盖回旧版本目录。
