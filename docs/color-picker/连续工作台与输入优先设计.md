# 连续颜色工作台与输入优先设计

## 范围与状态

本文件对应2026-10-21新增反馈。背景五种模式保留，rc13冻结包作为对照。2026-10-22本批P0/P1已实现并通过完整回归和解压包复验，rc14已双归档供用户测试，未公开发布。真实Win10 4K/200%、多屏混合DPI、HDR及本地控制台材质仍按下述边界验收，详见`docs/v1.38.3-rc14-候选验收.md`。

## 分批开发顺序

1. **P0 输入与HUD**：色值第一行、坐标第二行；坐标类型缩小弱化、同排共用基线。色值/坐标居中，坐标下留半行，再左对齐显示操作说明（按最新反馈修订）；仅取色会话临时启用英文键盘、分离IME、优先接收所列快捷键，窗口显示前准备好输入，退出/失败/失焦均清理并恢复。不拦截系统安全组合。
2. **P0 工具生命周期与入口**：右键菜单取色/颜色面板增加标准Phosphor吸管/调色板图标，适配浅深色和DPI。颜色面板独立运行，同一程序目录、当前用户会话单实例；看图窗口关闭不关闭面板，重复调用激活已有面板。
3. **P1 连续浏览与全局搜索**：统一内容视口、主题滚动条、系列分组连续流；删除上一页/下一页。搜索位于左侧“颜色”上方，覆盖历史、收藏、UI色卡、传统色、渐变及当前图片色卡，显示跨来源结果，右键可跳到来源系列和条目位置。
4. **P1 交互精简**：删除各页“颜色页／复制／收藏”操作排；颜色色块单击复制并设为当前颜色，回到左侧“颜色”即可编辑该色；右键提供收藏或编辑/删除。右上角星标收藏，同色已收藏时不重复添加、不覆盖旧名称；移除收藏走明确的删除确认。
5. **P1 历史与收藏**：删除复制/再编辑/删除/收藏/刷新/翻页/保存设置等按钮，去除UTC说明；选项即改即保存。历史底部保留清空/备份/恢复，清空/删除/恢复仍确认且保护原库。收藏采用相同列表表现，名称/标签编辑在右键编辑流程内完成。
6. **P1 深色与验收**：按钮、编辑框、下拉框、分组、列表和滚动条统一主题；键盘焦点/选中/禁用状态不丢失。新增修前失败的回归、全入口与直接解压包验证，候选双归档。

## HUD规格

- 保留180DIP基础宽度；放大镜和既有边缘避让规则不变。
- 色值第一行：13DIP半粗体；长Lab/CMYK允许居中换行，不省略有效数值。
- 坐标第二行：坐标数字13DIP半粗体；“全局坐标／相对坐标”11DIP常规次要文字，组合整体居中、共同文本基线，不以两个不同字号的行框各自垂直居中。过长时分行，不叠字或截断数字。
- 快捷键说明11DIP次要文字，左对齐换行；坐标之后增加0.5个说明行间距（96/192/288DPI分别9/17/26物理像素），无后续内容不留空隙。状态提示也按下方内容左对齐。F2“显示取色快捷键说明”继续生效并持久化。
- 输入优先仅在活动取色会话中存在，F2菜单打开时让原生菜单处理方向键/Enter/Esc。退出、截图失败、程序关闭均释放资源；不常驻键盘钩子，不记录无关输入。

## 独立面板契约

- 单实例以规范化EXE路径派生命名，避免候选版和稳定版互相复用或混用配置；限制当前登录会话。
- 进程间只传激活、RGB颜色、外观偏好和最大512×512的当前图片缩略像素；不传原图路径，不复制原图文件；限制长度、验证命令和数值，不执行任意命令。
- 普通“打开颜色面板”只激活，不用新看图进程默认颜色覆盖已有面板。明确取色送入时采用新色。
- 面板自行关闭结束工具进程；看图进程只停止自己正在进行的屏幕取色，不发送关闭颜色面板。
- 单实例启动竞态、旧实例退出竞态、无法启动、无法激活都必须有有界处理及明确反馈，不留下看不见的常驻进程。

## 连续流与交互

- 七个导航顺序不变。左栏顶部增加全局搜索，不再在各页重复同一搜索框。
- 色卡/传统色按系列分组，下滑自然进入下一组，无需先选组再翻页；系列选择若保留，仅作为跳转锚点。
- 渐变按基本预设/参考系列分组连续显示；图片色卡按导入图片分组，每组保留图片来源和提取颜色，向下连续浏览。
- 大集合使用可见区绘制或有界复用，不能为数千色卡创建数千HWND。滚轮按视口滚动，滚动位置不跳回顶部；右键菜单取消不产生复制/收藏。
- 搜索结果单击复制/设当前色；右键“跳到来源”退出搜索结果、切换导航并定位对应条目。空结果明确显示，不覆盖当前色；搜索特殊字符作为字面文本，不拼SQL。
- 色块单击复制不自动新增历史（除非用户开启复制即记录），回看历史也不重复记录。颜色选择与复制失败分别反馈，剪贴板忙不能假称复制成功。
- 自动保存失败保留未保存状态并提示，不能静默吞掉异常。删除/清空/恢复不因精简按钮而失去确认。

## 验收矩阵

- 三语、浅/深色、96/192/288DPI、长色值/负坐标和显示器边缘；截图核对居中与层级。
- 中文IME打开/有组合串/英文输入时，Shift、P、C、E、Enter、Esc、方向/Ctrl方向、F2、F5和空格的真实输入；取色退出后原输入法恢复；F2菜单不被截键。
- 看图窗口关闭后面板可用；再次打开看图并调用面板同一实例；两次并发启动、面板关闭后重开、候选与稳定目录互不抢占。
- 每页连续跨多个系列、顶部/底部边界、长集合、搜索跳转、右键取消、单击复制、收藏状态、历史自动保存与重启恢复。
- 深色下全部控件含滚动条无白色突兀区域；各按钮焦点、禁用、键盘导航可见。
- 全量回归失败保留原始日志，组件通过和包完整性不替代整版；NAS不可用时明确单归档状态。
