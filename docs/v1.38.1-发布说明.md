# YeImageViewer v1.38.1

本次正式版集中改进拖拽手感、设置页与文件关联，并修正键盘平移方向。

## 新功能

- 点击工具栏手掌控件，选择智能加速或十二档固定倍率：0.1×、0.25×、0.5×、0.75×、1×、1.25×、1.5×、2×、3×、5×、7×、9×。按住 Shift 临时精细拖拽，不修改保存的倍率。
- 设置 → 常规新增“拖拽惯性滑动”，默认关闭。开启后快速左键拖动并松手，图片继续滑行并减速停止。独立灵敏度 1～9 档，默认第 5 档，越高滑行越久、越远；不与拖拽倍率重复相乘。

## 修复

- 默认 W 向上、S 向下、A 向左、D 向右，图片按屏幕方向移动。自定义快捷键保留，鼠标和滚轮方向不变。
- 文件关联页及滚轮设置在高 DPI 下的布局和点击错位；补齐 Windows 打开方式登记，提示用户在系统默认应用中完成确认，不覆盖其他程序的受保护默认选择。
- 默认实际大小与观看规则互相覆盖、快速连续拖拽误触双击、捕获外负坐标跳变、长间隔慢拖被误判为加速，以及失焦后浮层／捕获残留。
- 全部设置、拖拽模式、固定倍率和独立灵敏度的切图与重启持久化回归。

## 下载与更新

提供裸 `YeImageViewer.exe`、绿色 ZIP 和体积更小的 7z，无安装程序。退出旧程序后替换文件，保留旁边的 `YeImageViewer.db` 即可保留设置；缩略图 DLL 为可选组件。

发布前需完整回归及解压包复验通过。自动化覆盖包含 WASD 实际屏幕方向、惯性九档、旧拖拽、设置持久化、快捷键／滚轮和既有解码等流程。Win10 4K 与混合 DPI 双屏尚待真机验证；详细证据与边界见仓库 `docs/v1.38.1-发布测试报告.md`。
