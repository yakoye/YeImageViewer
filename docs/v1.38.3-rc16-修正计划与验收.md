# v1.38.3-rc16 修正计划与验收

本批响应 2026-10-22 的五项反馈。只交付开发预览，不公开发布；rc15 产物不覆盖。

## 修改范围

1. **图片背景与图外留白分离。** 菜单三语改为“图片背景色”，保留透明、白色、黑色、毛玻璃、棋盘格及棋盘浅深配色；新配置默认棋盘格。普通、沉浸模式图片外恢复原 `0x99000000` 透明灰。已有用户主动选择的图片背景仍保留，不擅自重置设置。
2. **取色说明缩进。** 九条快捷键说明每行增加四个空格，色值和坐标仍居中，坐标下保留半行间距。实际字号测量使用同一缩进文本。
3. **色卡紧凑布局。** 色卡和传统色单元由72改为48逻辑像素，名称、HEX各占一行；长名称省略，不再换成第三行。历史/收藏的单列记录保持原高度，键盘滚动跟随实际高度。
4. **输入法不改系统配置。** 移除加载和切换美式键盘布局的调用；屏幕取色窗口摘除IME上下文，颜色数值框禁用IME合成。色卡搜索、名称等中文文本输入保留；不删除无法确定来源的既有系统键盘布局。
5. **图层界面与加载。** 使用固定上游 Photocraft Pro/ProLight 中性灰色阶，增加行分隔、眼睛固定列分隔、属性框、选中行、标签栏及滚动位置指示。行高34、缩略图24逻辑像素，压缩底部说明区。先交付只读元数据树，再异步导入完整引擎；两阶段共享输入字节、不复制大型PSB，不在后台修改UI正读取的Source。保真核对延后到首次修改前，而非阻塞初次列表或永久删除差异提示。
