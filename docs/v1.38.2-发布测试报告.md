# v1.38.2 发布测试报告

日期：2026-10-15。用户已明确授权正式公开发布。候选版验证记录保留在 `docs/v1.38.2-rc1-设计与测试报告.md`，不覆盖候选包及历史正式版本。

## 范围与闸门

本次仅将已完成的候选功能晋升为正式版：独立阅读滚轮配置、单图新默认、二十档灵敏度滑杆与工具栏入口、WASD 连续平移及工作区降级缩放时的非客户区 DPI 修复。不新增产品行为，清除预发布标记，版本为 1.38.2／1.38.2.0。

最终提交后执行 `./runTests.ps1`，日志 `artifacts/v1382-final-tests.log`；必须退出 0 且末尾为 `All regression tests passed.`，不使用候选版旧日志代替正式构建验证。预期覆盖：749 项单元／集成、80 项观看、54 项原拖拽、56 项方向／改绑、6 项连续平移、11 项单图默认滚轮、102 项独立阅读滚轮、56 项滑杆、148 项惯性、113 选项组合／339 项常规设置持久化、94 项快捷键／滚轮、20 项 DPI，以及 PNG 143 文件逐字节一致、真实格式 44 项、色彩／打印／剪贴板／文件操作／源码正逆护栏／归档契约等；实际结果以本轮日志为准。

按发布检查技能核对源码、版本、配置迁移、构建、解压与远端下载。程序必须嵌入最终提交号；包内 EXE 和 DLL 与通过完整闸门的构建一致。正式包执行独立临时配置下的滑杆、键盘平移、单图与阅读滚轮、DPI 冒烟，不污染用户 DB。

首轮正式闸门在全屏断言失败，保留 `artifacts/v1382-first-fullscreen-failed.log` 与 `artifacts/v1382-fullscreen-failed-state.txt`。当时配置 `pref323=2` 已写入，但实际 `shape=1` 仍为上一形态：设置线程写值先于主渲染线程消费变更，测试只等待配置值不足以证明窗口完成。隔离 `artifacts/v1382-fullscreen-diagnostic.log` 实际切换通过。补齐实际 `shape=2` 且画面稳定的有限等待，保留原全屏断言，不调整产品行为或放宽条件；最终完整流程重新执行。首轮另有 Shift＋F10 因无法获得前台跳过，不能计为通过。

1. 完整闸门通过后打包裸 EXE、根目录可见 EXE 的 ZIP／7z、SHA256SUMS；校验版本、提交、CRC、十文件布局、无 DB 及来源哈希。
2. 正式包复验通过后归档到两个 `yakoye-release/YeImageViewer/v1.38.2`，校验大小／SHA-256，不覆盖冲突文件或候选历史。
3. 推送已验收提交和 v1.38.2 标签，公开 GitHub 正式 Release；重新下载四个资产，逐一核对大小／SHA-256 和压缩包 CRC。

更新前备份 EXE 旁的 DB。保留 v1.38.1 及其原配置以便回退，旧版可能重置不认识的新配置版本。关键输入／文件操作回归或闸门失败时停止公开发布；已公开后不替换同名历史资产，应另发修复版本。
