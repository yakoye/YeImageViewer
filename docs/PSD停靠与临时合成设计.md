# PSD 停靠与临时合成设计

> 2026-10-22更新：以下为旧受限C++方案与历史验收记录，保留追溯，不再作为完整对齐的最终路线。用户已明确要求直接复用PhotoCraft及对齐PS界面/操作，当前新方案与欠项见[PhotoCraft图层后端移植与对齐计划](PhotoCraft图层后端移植与对齐计划.md)。

日期：2026-10-20。状态：已确认需求，首批候选开发与验收中。使用系统设计、架构决策和分层测试流程。

## 用户确认的目标

主窗口右侧显示图层／通道，不再通过菜单弹出独立图层窗口。用户可以关闭多个图层的眼睛开关，主画布实时重新合成；提供恢复文件原始可见性。所有显隐都只影响浏览，不写PSD，不把它误称为图层编辑器。

## 架构决策

保留 `PsdCompositeDecoder` 作为默认原始图片解码器；未改动显隐时始终显示文件自带合成图，确保原始看图兼容性不被新合成器拖累。

新增 `PsdRecompose` 处理临时可见性、图层坐标、像素混合、分组与支持的蒙版；`PsdDock` 负责主窗口内面板、异步请求与显示状态。单个后台任务串行复用已解码图层，快速点击合并成最新代请求；旧图片／旧显隐结果不得覆盖当前画布。切到普通图片自动收起，切PSD重新加载，关闭再打开恢复文件状态。

右侧面板可拖动分界线调整宽度；展开和收起不重设当前手动倍率。适应窗口按剩余画布计算，真实大小仍为100%。面板滚轮只滚列表，不误缩放图片；Esc先收起面板，不触发全局关闭。无边框窗口最右上角仍关闭软件，面板自身关闭键另设热区。

原始显隐与临时显隐分离。图层组的眼睛影响其后代，但不改子层自己的开关；组可折叠。单层原始栅格预览单独标明，不假装重建效果。通道页首批明确标为“显示通道”，展示当前预览的sRGB R/G/B/Alpha；**不是完整原生PSD专色／保存Alpha色版管理器，也不把转换后的RGB冒充CMYK原通道**。

显式保存副本在临时预览完成后导出当前画面（再应用浏览旋转／镜像），转为sRGB，不嵌入面板。沿用CREATE_NEW拒绝覆盖与失败清理规则。浏览、切图、关闭均不写原图。首批面板宽度只保留在当前运行期间，显隐不跨重启持久化。

## 合成能力边界

首批支持8位RGB PSD/PSB：普通、正片叠底、滤色、叠加、变暗、变亮、差值、排除、强光、柔光；图层不透明度和Alpha；普通隔离组、100%穿透组；基本绝对坐标像素蒙版（包括禁用及反相）。按文档原坐标裁剪，全部隐藏时保留真正透明，不回退到原图。

暂不承诺16/32位、CMYK/Lab实时重合成；不忽略图层效果、调整层、矢量蒙版、剪贴链、非默认Blend If、特殊填充不透明度、穿透组部分不透明度、带密度／羽化或特殊坐标的蒙版。遇到这些当前可见元素时拒绝本次重合成，恢复上次已接受的开关／模式并保留上一画面，在面板说明原因与关联图层；不静默降级为普通混合。未受支持但隐藏的图层不影响其余受支持图层合成。

原始合成图仍可按原解码能力打开，读取图层失败不等于整张PSD打不开。首批互动读取文件≤256MiB、合成画布≤16Mi像素、栈深≤8、图层缓存约128MiB；超过时明确提示安全上限，不无限展开全部图层。

选择现有原生C++路径而非立即引入整个Rust编辑引擎，是为了控制依赖、启动成本和设置兼容性；代价是首批合成能力有明确限制。若真实素材主要依赖剪贴链、效果、调整或高位深，则需要下一阶段扩展／替换合成后端，不能靠继续添加普通叠加特例假装完整支持。

## 验收计划

1. 独立数值／像素单元：透明度与不透明度只乘一次、10种混合、图层顺序、多层同时隐藏、全透明、负坐标、组开关／隔离不透明度、像素蒙版、边界与取消、不支持项明确失败。
2. 最小PSD夹具 `test/image-tools/visibility-stack.psd`：368字节、2×2像素、3层（半透明红／绿色／蓝色）；自动生成代码保存在 `PsdRecomposeTests.h`，原合成像素为独立给定值。
3. 真窗口：菜单不创建旧对话框、两个眼睛同时关闭、画布截图像素匹配、全部透明、快速点击最新状态、恢复原合成图、显示通道、Esc、切图与源文件SHA-256不变。无读屏专项必须明确SKIPPED，不能代替完整窗口验收。
4. 完整 `runTests.ps1`、解压候选包复验、双归档大小/SHA-256；仅候选，不公开发布，不覆盖已有候选。
5. 使用用户提供的真实PSD／PSB只读核对，记录源文件哈希；用独立参考像素核对真实分组、蒙版与混合，不能用合成器自己的输出当金标准。

## 真实素材与独立参考核对（2026-10-20）

用户目录 `C:\Users\color\Downloads\支持不好的图片文件` 的 `43.psd` 和 `42.psb` 都是2362×1575、8位CMYK，分别30与58条图层记录，含剪贴、效果、线性减淡及像素蒙版。原始合成图可读；**此候选不能对它们进行准确的多层实时重合成**，不能将RGB夹具通过等同于这两份文档通过。单层原始栅格预览与图层列表是另一路能力，不冒称完整合成。

由真实记录发现读取顺序错误：文件从底向顶存放，目录边界在组头之前。通道按物理顺序绑定后统一反转，向UI及合成器提供自顶向底的规范顺序。修正最小夹具的物理顺序，旧读取器在新断言下失败；新增外部MIT许可的ag-psd分组夹具，保留上游独立合成图作参考。

外部样本又暴露RGB最终合成图的白色衬底问题：合成透明通道存在时，在原位深精度下撤去白色衬底，再量化到8位；单层栅格复用解码时显式关闭此步骤。外部分组重合成与文件自带合成图按Alpha和预乘RGB比较，舍入容限2 LSB；修改前最大差64，修改后通过。源默认合成解码与缩略图共用该修正。

兼容第三方无衬底写入器：全图半透明RGB必须符合白色衬底恒等式 `颜色 >= 1-Alpha`（允许编码量化1 LSB），只要存在反例就保留直通颜色；不按文件名或尺寸识别。完全符合恒等式但由第三方写成直通的浅色图仍有编码歧义，当前按PSD白衬底约定解释，不声称能无歧义识别所有写入器。整数位深先在原整数域相减再归一化，避免浮点减法使精确半值跨舍入边界。8位两次量化的固有误差用明确整数数值测试，16/32位另测，未放宽既有缩略图比较容限。

新增只读 `--psd-layer-audit <PSD/PSB> <报告目录>` 清点色彩、尺寸、顺序、分组、效果及通道，核对原合成、临时开关能力和原始单层预览；不写源文档、不代替真实窗口验收。
