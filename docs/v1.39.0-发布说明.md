# YeImageViewer v1.39.0

**本版本基于 v1.38.3-rc18。** 保留该候选现有功能与内置数据，汇总此前候选的兼容性、颜色工具、图层与交互改进。公开发布以 GitHub Release 实际状态为准。

## 本版包含

- 图片浏览：既有大量静态/动画/RAW 格式、连续阅读、观看规则记忆、拖拽倍率/智能加速/惯性滑动，以及可配置右键拖动缩放。
- 颜色工具：屏幕快照取色、七种颜色格式、像素微调、快捷说明开关；工具栏吸管左键取色、右键颜色面板。成功取色后两秒内右键带色进入面板。
- 独立颜色工作台：看图关闭后可继续使用，重开复用同一面板；色轮和数值联动、撤销/重做、原色恢复、永久历史、收藏、全局搜索、色卡/传统色/渐变色/图片色卡、备份恢复及浅深主题。保留当前内置数据库，来源见随包说明。
- 图层与通道：PSD/PSB 就地面板、分组、显隐、像素蒙版、混合模式、不透明度和填充的临时预览；PhotoCraft 后端及有界缩略图，不因浏览改写源文件。
- 轻加工：修复非方形图片旋转/镜像后截断与拉丝；普通窗口/沉浸显示切换保持显示倍率。显式保存原图、保存副本或不保存，紧凑提示优先避开图片留白。
- 交互：按钮、色块、滑杆和图层条目的悬停反馈；色块松手确认/拖出取消，图层滚动条拖动及轨道翻页。
- 兼容性：PSD/PSB 保存合成图、CMYK TIFF、RAW 错误检查及经过验证的内嵌预览回退、大型二进制元数据限量等修正。

## 明确边界

- 图层临时重合成不保证等同 Photoshop，复杂 CMYK、调整/效果、智能对象等可能有差异；原始状态保留文件保存的合成画面，可恢复。多选/范围、完整键盘操作、通道组合等高级编辑尚未实现。
- 取色仍为快照；空格/F5 重新抓屏。实时取色、可配置系统全局热键、AI 配色不在本版。
- 保存原图只开放经过校验的 8 位单图 PNG/JPEG，并保留原始备份；高位深、动图及复杂格式使用副本，不承诺保留所有原格式结构。
- 不把单屏或离屏检查宣称为所有 Win10 4K200%、多显示器、混合 DPI、HDR 硬件验收。
- 毛玻璃图片区域的精确系统材质隔离仍有限制。高级颜色导入导出、删除撤销、多图比较和外部编辑器排序等后续项目不冒充已完成。

## 使用与回退

请完整解压绿色 ZIP/7z，保持 EXE、图层后端 DLL、缩略图组件及许可文件在一起。不要只替换 EXE。升级前备份原程序目录的配置及颜色数据库；若需要回退，使用单独保存的旧版完整目录，避免旧程序改写新版数据。

包附 SHA256SUMS。正式发布后同步提供 GitHub 下载及本地/NAS 项目版本归档。
