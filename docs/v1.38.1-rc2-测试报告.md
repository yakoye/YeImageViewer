# v1.38.1-rc2 惯性滑动候选版测试报告

日期：2026-10-14。范围：用户确认的默认关闭、独立灵敏度、快拖松手后惯性减速；不公开 GitHub，不推送，不覆盖 rc1。

## 使用方式

设置 → 常规 →「拖拽惯性滑动」选择开启；「惯性滑动灵敏度」共 1～9 档，默认 5。档位越高，衰减越慢、滑行越远。

图片上按住左键快速拖动并松手：先按工具栏自动／固定倍率跟手，再沿释放方向继续滑动并减速停止。惯性不再乘一次倍率。慢拖、最后明显减速、停顿后松手、使用过 Shift 精细模式的手势仍松手即停。再次输入或触边可立即停止。

默认关闭时原有拖拽保持不变；升级旧配置也默认关闭。可以独立保存惯性灵敏度，即使开关关闭也不丢档位。

## 实现与兼容

- 新设置在 reserve[360..367]，固定 4096 字节布局及文本区不变；原十二档／智能加速存储不被覆盖。
- 固定容量 64 条速度样本，按最近约 120 ms 计算，不在高频输入路径分配内存。慢帧／合并消息按真实时间剪裁，不能把间隔强行缩短来制造速度。
- 快速判断使用可拖动轴的鼠标逻辑速度；衔接速度使用实际限位后的图片位移，不用已经触边的虚假输入速度。
- 九档时长为 0.18、0.255、0.33、0.405、0.48、0.555、0.63、0.705、0.78 秒；速度为 `v(t)=v0*(1-t/T)^2`，起点衔接当前速度、终点速度为零。相同释放速度时，距离随档位严格增加。
- 速度有视口相关上限；帧位置按时间积分，不因 30／60 FPS 分帧不同而改变终点。
- 普通／沉浸图片与连续阅读复用策略；自然跨阅读页不作为人工切图取消，边界不回弹。再次鼠标、滚轮、按键、菜单、切图、旋转、缩放、调整窗口、失焦、捕获异常取消动画。
- 松手前补齐可能被合并的末次坐标增量。先计算释放速度，释放捕获后再启动惯性，避免同步捕获回调把新动画取消。
- Shift 精细状态按整个鼠标手势记录，不能被中途按键清理速度历史时意外清掉。
