# rc18 交互反馈与紧凑保存提示

日期：2026-10-23。开发预览候选，已打包双归档，不公开发布，不覆盖 rc17。离屏验证通过，完整桌面回归未闭环，不能标记为正式验收完成。

## 本批实现

- 颜色面板公共按钮跟踪鼠标进入/离开，正常、悬停、按下、选中、禁用分开；导航、取色、收藏、逐行复制、原色/当前色、建议色与近期色均有反馈。
- 色轮及 S/V 滑杆悬停增大定位圈；色块悬停只改变边框，不改变真实颜色。
- 连续色卡、历史、收藏及搜索结果增加悬停轮廓，列表收藏图标和滚动条反馈；按下后须在同一色块/同一星标区域松手才执行，移出或丢失捕获取消。
- 图层/通道的标签、行、属性、关闭与底部预览入口有悬停反馈；当前标签保留强调线，图层滚动条支持拖动和轨道翻页。
- 保存提示从顶部居中大条改成 284 DIP 紧凑卡片；优先右下，按当前图片实际显示范围比较四角遮挡，有留白时避开图片。三个按钮按文字分配宽度，“否”不占三分之一。图片铺满窗口时只能减少遮挡，不能承诺完全不覆盖。
- 成功取色后的两秒内，按右键并松开带当前颜色进入独立颜色面板；取消取色和 C 复制不退出不启用。窗口期内只捕获这对右键，其他点击/滚轮取消等待；钩子退出释放，不添加键盘布局。超时恢复普通右键。
- 隔离运行目录补拷贝图层后端许可文件，防止完整回归在二级隔离目录准备阶段失败。
