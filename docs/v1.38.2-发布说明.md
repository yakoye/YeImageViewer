# YeImageViewer v1.38.2

本次改进滚轮习惯、二十档拖拽控制与键盘平移，并修复设置窗口的 DPI 尺寸问题。

## 主要变化

- 单图默认普通滚轮缩放、Ctrl＋滚轮上下拖动、Shift＋滚轮左右拖动。
- 连续阅读拥有独立滚轮配置，默认普通滚轮沿阅读方向滚动、Ctrl 缩放、Shift 沿另一方向拖动；纵向／横向阅读自动切换对应方向。设置 → 快捷键可分别调整两套配置。
- 智能加速与惯性灵敏度扩展为 1～20 档滑杆。原 1～9 档强度和默认第 5 档不变，新增档位继续增强；惯性仍默认关闭，固定十二档倍率保留。
- 工具栏手掌弹层提供相同的灵敏度滑杆与惯性开关，和设置页同步、重启保存，支持方向键及 Home／End 微调。
- WASD 长按按时间连续平移，更平滑且不依赖系统按键重复速度；W 把图片上拖、S 下拖、A 左拖、D 右拖，短按仍移动一步，松开长按立即停止。
- 修复工作区不足、窗口内容缩放降低时，标题栏／边框 DPI 导致设置和打印客户区与画布尺寸不一致的问题。

## 更新与回退

提供裸 EXE、绿色 ZIP 和 7z，不提供安装程序，不包含用户配置。更新前退出程序并备份旁边的 `YeImageViewer.db`。

整套旧单图默认滚轮会迁移为新默认，其他自定义组合和键盘绑定保留。旧配置不能区分“未修改”与“刻意改回整套旧默认”，后者也会迁移，可在快捷键设置中重新选回。新连续阅读配置独立保存。

降级到 v1.38.1 时应恢复备份的 DB，避免旧程序重置它不认识的新快捷键／灵敏度配置。

## 验证边界

完整自动化回归与绿色包复验作为发布闸门，详情见 `docs/v1.38.2-发布测试报告.md`。当前单屏环境不能代替 Win10 4K／200%、混合 DPI 多显示器和小时级耐久验收。候选包一次滑杆冒烟中曾出现浮层关闭，之后两次隔离复验未再出现，原因尚未确定，保留记录，不宣称已彻底消除间歇风险。
