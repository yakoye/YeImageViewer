# 轻工具与浏览安全设计

## 交付规则

先交付已通过完整回归的缩略图优化快照（v1.38.2-thumbnail-20261017），再开发本轮功能。候选包必须本地/NAS 双归档，公开发布暂停；每个快照单独命名、不覆盖历史产物。

## 安全边界

旋转和镜像仍只是浏览操作（现有观看记录机制不变），切图和退出不触发图片写入。新增“保存副本”只在主动执行时导出当前原始分辨率画面；不保存窗口背景、缩放和 UI。不覆盖源文件，也不覆盖任何已有副本，避免误操作。默认 PNG，保留透明；JPEG 用白色合成透明区域。导出为 8 位 sRGB 平面图，不承诺保留原始位深/元数据/动画/RAW 数据/PSD 图层。取消、加载未完成或解码错误均不落盘。编码完成后才创建新文件，写入失败只清理本次新建的文件。

## 呈现

不扩充底部主工具栏。在软件内右键菜单增加“轻工具”子菜单，集中提供取色、PSD 图层查看、保存副本；原来旋转/镜像按钮保留。取色采用独立小面板，可与绘图软件并排；图层采用按需打开的列表/预览窗口，不常驻占空间。首版不做多图比较。

## 取色

屏幕取色冻结当前虚拟桌面，支持负坐标多显示器；点击确认，Esc 取消。放大镜只显示屏幕像素，不承诺 HDR 原始色值或源文件未色彩管理数值。确认后显示色块、#RRGGBB、RGB；一键复制两种文本；允许输入 HEX/RGB 微调和系统颜色对话框。面板布局按实际 DPI 调整。

## PSD 图层

主程序和缩略图继续使用严格的 PsdCompositeDecoder 合成图路径，不修改原文件。另建有边界/内存限制的图层读取器，先读索引，再按选择解码单层。显示名称、可见状态、透明度、类型；不伪装支持混合模式/调整层/智能对象重建。只预览文件中已存储的栅格像素，文本/智能对象等没有可用像素时明确提示。不把整个文档所有图层一次解码进内存。

字段与压缩布局依据 [Adobe PSD/PSB 文件格式规范](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)；单层通道重用现有合成解码器完成像素/色彩转换，文档合成图本身不重建。

## UI 缺陷

工具提示使用实际字体测量和实际 DPI，不再按每字 7/14 像素估宽、固定 180×30 像素。加载标记同样使用实际测量。关闭按钮正方形贴住无边框画布右上角，最右最上像素可命中。分隔线颜色降低对比，不只改 BGRA alpha（最终上传不能假设任意线条会再做透明混合）。

退出沉浸恢复边框仅改变窗口，以当前显示倍率定尺寸；同步 WM_SIZE 不重新执行锁定/默认缩放。窗口超出工作区时限制窗口，不强制重缩当前图片；下一张继续用户规则。2000×4000 纵向最小夹具的旧路径会把22.55%改为75.60%，新增真实进程探针同时验证倍率及显示矩形尺寸保持。

## 验证

新增自动化覆盖像素方向/镜像、源文件不变、拒绝覆盖、透明色合成、HEX/RGB、负坐标屏幕映射、PSD 图层截断/边界/压缩/名称、96/144/192/288 DPI 文本矩形与右上角命中。运行完整 runTests.ps1 和包内冒烟；真实 Win10 4K/200%、HDR 和混合 DPI 多屏未在当前机器验证时保留未验证说明。
