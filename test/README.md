# 回归测试素材

此目录保存曾触发真实缺陷的原始文件。新增素材时，应同时在根目录的 `runTests.ps1` 中加入自动化回归步骤，并记录缺陷现象和预期行为。

## Image crash/dji_export_photo_20260809221510044.jpg

- 来源：用户提供的 DJI MotionPhoto 原图。
- SHA-256：`00E55EF88EF3897D52D950839C676508D21F3D26AA0D549F8B4CFA96630FFC72`
- 历史缺陷：内嵌视频的 H.264 像素格式无法识别，FFmpeg `libswscale` 断言使程序以 `0xC0000409` 退出。
- 预期行为：无法解码内嵌视频时安全降级为静态 JPEG，窗口保持打开并正常响应。

## HDR 色彩通道回归

- 上游问题：[`jark006/JarkViewer#45`](https://github.com/jark006/JarkViewer/issues/45)。
- 历史缺陷：Radiance HDR 的 RGB 数据被当作 BGRA 显示，表现为红色与蓝色互换。
- 对比图：`HDR color error/HDR_compared.png`，SHA-256 为 `8010D5E627002BEE7591B86EF4BE965872C66C397F402F99F59EBF5D52C8F49D`。
- 原始文件：`HDR color error/HDR.hdr`，2560×1600，SHA-256 为 `1A1A661E0A22BECBE019B6C095004315351F28600D9BD7600BD933BEB351E5D5`。
- 自动化方式：`YeImageViewerTests` 先用内存中的纯红、纯蓝最小 Radiance HDR 验证精确 BGRA 通道顺序，再解码真实原图并验证尺寸和红/蓝通道统计关系；`runTests.ps1` 会先校验真实原图哈希，防止夹具被意外替换。

## 背景选择回归

- 复用透明矢量图 `SVG Blurring/SittingHuman.svg` 验证右键菜单中的“透明、白色、黑色、毛玻璃”四种背景。
- 预期行为：透明模式显示棋盘格，白/黑模式精确合成透明像素，毛玻璃模式将预乘 Alpha 图像交给 Windows DWM 桌面亚克力合成；不支持的系统回退为主题底色。
- 自动化方式：`YeImageViewerTests` 对四种背景和半透明像素做精确像素断言；`runTests.ps1` 打开真实 SVG 并依次切换四种菜单命令，验证窗口始终存活且可响应。

## 悬浮工具条与 Esc 回归

- 复用 `SVG Blurring/SittingHuman.svg` 验证主窗口的右下角工具条和窗口状态恢复。
- 预期行为：上一张、下一张、左旋转、右旋转和设置使用同风格的 30×30 图标在右下角横向排列，左下角不再触发打印。
- `Esc` 优先退出全屏，其次恢复最大化窗口；普通窗口仅在“Esc关闭图片”开启时退出，该设置默认关闭。
- 图片旋转状态按规范化完整路径保存；重新构造状态存储后必须恢复，回到 0° 时删除多余记录，损坏的状态文件安全回退为 0°。
- 打开图片先进入目标显示器工作区的无边框沉浸预览：小图按 DPI 逻辑 100% 显示，横图受 90% 宽度和 82.5% 高度限制，竖图只受 90% 宽度限制并允许高度溢出；长竖图默认显示中部。
- 单击图片保持沉浸预览并允许拖动；单击图片外背景空白或按 `Esc` 退回首次打开图片尺寸对应的带边框窗口，之后切换图片不改变外框；每张图片继续采用自己的沉浸预览百分比，不随大窗口拉伸。
- 退回窗口必须恢复启用、激活、键盘焦点和鼠标状态，标题栏关闭必须真正销毁窗口与进程；设置页各行不得重叠并使用 18 像素字体。
- `F2` 不再打开设置窗口；设置页窗口级回归改用菜单命令触发。
- 沉浸和普通窗口的图片外区域都使用约 60% 不透明的黑色 DirectComposition 客户区透出桌面，不使用毛玻璃；拉大普通窗口后效果保持一致，用户背景选择只作用于图片区域，右上角关闭按钮必须常驻，普通窗口最大化请求必须重新进入相同的沉浸路径。
- 设置窗口在沉浸图片上方移动后，主窗口必须保持无边框、响应和稳定合成；退回普通窗口后继续使用透明合成，同时恢复标题栏、缩放边框和完整鼠标交互。
- “记住最后使用的显示器”默认开启；设备名匹配忽略大小写，目标显示器断开或选项关闭时回退主显示器，负坐标窗口位置可往返恢复并被限制在工作区内。
- 滚轮组合交互：`Shift + 鼠标滚轮`只垂直滚动当前图片，`Ctrl + 鼠标滚轮`切换上一张/下一张；普通滚轮继续缩放，同时按下 Ctrl 与 Shift 时 Ctrl 切图优先。
- 自动化方式：`YeImageViewerTests` 校验 Picasa 示例尺寸、横竖图策略、退回客户区、半透明黑色 Alpha 策略、关闭按钮不依赖可选 SVG、设置控件无重叠、滚轮组合键方向和优先级、图标渲染、旋转状态重载和 Esc 决策优先级；`runTests.ps1` 验证 EXE 版本为 `1.36.10.0` 与嵌入 Commit ID，并在真实窗口中回归 DirectComposition 客户区、Ctrl 滚轮切图、普通滚轮缩放、无边框启动、图片区不退回、背景退回、交互恢复、标题栏关闭、最大化进入沉浸、常驻关闭按钮、设置窗口跨图片移动、固定窗口切图、全屏、普通窗口 Esc 以及工具条悬停。
