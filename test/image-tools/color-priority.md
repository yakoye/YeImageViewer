# rc8 高优先级入口与联动最小夹具

- 布局反例：同一组`flipVerticalRect`、`screenPickerRect`、`panMultiplierRect`，在300/800/3840像素窗口和96/192/288DPI下必须按顺序、不重叠。旧rc7的9种组合全部失败，新实现还检查分隔线不穿过手掌按钮。
- `orientation-alpha.png`：既有3×2非对称RGBA小图。16组旋转/水平镜像/垂直镜像的坐标逆映射与导出变换参考逐像素一致，保留透明像素的原RGB，不取棋盘格。
- `two-layers.psd`：既有最小双图层PSD；`two-layers.psdt`为相同字节的模板扩展夹具（SHA-256均为`17D3E714E4E36A1E7DD500C4BA31E9519AA96EEF26DFB1A1A369F8C30BB36B3B`）。实际元数据提供入口；模板、同路径重开、切普通图的能力清理也有回归。PNG、扁平与损坏记录不能以扩展名冒充图层能力。
- HEX `#12ABEF`、RGB `(18,171,239)`与用户示例`(77,46,46)`：七格式往返、色轮/SV、共享当前颜色与无效输入拒绝。
- 屏幕专项仅抓取本测试绘制的已知色块；生产HUD与消息路径验证E/面板确认不额外写剪贴板。覆盖层仍为快照，不把模拟DPI/消息按键写成真多屏/硬件键鼠通过。
- 主窗口专项检查真实吸管点击/右键弹出、图片取色、面板颜色、菜单条件、重复会话、关闭清理；独立命令确认无`D3D11WndClass`且退出后没有残留进程。

素材全部为既有程序化小夹具，不包含用户PSD或桌面内容。原始设计测试表不批量改PASS；逐批执行证据以候选报告和完整回归日志为准。
