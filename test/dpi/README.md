# 工作区限位后的设置窗口 DPI 回归

最小复现使用 `scripts/test-viewing-regressions.ps1 -SettingsDpiOnly`：程序和配置复制至测试自己的临时目录，PNG 页面由脚本生成，不需要用户图片。向真实设置窗口发送 96／120／144／192 DPI 变化，在当前显示器工作区较小时触发内容缩放限位。

旧实现把内容有效 DPI 用于非客户区计算。当前屏幕的有效 DPI 为 131，旧窗口客户区与 `620 × 131 / 96` 画布不等大；独立尺寸断言失败。新实现按窗口真实 DPI 计算 Windows 标题栏／边框，按有效 DPI 计算内容，客户区回到 846×846。

测试独立读取工作区、计算有效比例，核对客户区尺寸、末行标签像素、关联结果对话框和隔离注册表中的 PNG 能力。点击不修改用户文件关联。请求值与有效值分别记录：当前小屏上的降级不是真实 4K／200% 验收，多屏和真实高 DPI 仍需对应设备。

修复前证据：`artifacts/dpi20-isolated-fit.log`。定向修复后证据：`artifacts/dpi20-after-fix.log`。最终交付仍须运行完整 `runTests.ps1`。
